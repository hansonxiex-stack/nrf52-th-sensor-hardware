**电气类型说明**（输入 / 输出方向 → KiCad 电气类型）：

| 引脚 | 方向 | KiCad 电气类型 | 说明 |
|---|---|---|:---:|---|
| VDD、VSS | 电源（+ / −） | Power Input | ERC 据此识别电源网络 |
| SDA | 双向（数据手册标 I/O） | Bidirectional | 开漏 I²C，也可标 Open Collector，Bidirectional 通用性更好 |
| SCL | 输入（数据手册标 I） | Input | I²C 时钟，只进不出 |

**为什么输出用 Passive 而不是 Output**：段码脚物理上是输出（驱动 LCD 玻璃），但它是 LCD 偏置波形（非标准逻辑电平），且下游是 LCD 玻璃、没有电气模型。若标 `Output`，ERC 会报「output 未连接到 input」的误告警；标 `Passive` 既不区分方向、又不触发误报，是段码 LCD 驱动的通用做法。

## 3. 逐步操作（Symbol Editor）

1. **打开 Symbol Editor**：原理图编辑器菜单 `Tools → Symbol Editor`（或启动器里直接进 Symbol Editor）。

2. **建库（一次性）**：
   - `File → New Library`，选 Project（项目库）或 Global，命名如 `HT16C21A`，生成 `HT16C21A.kicad_sym`。
   - 若已有自定义库，也可在库列表右键 → `New Symbol`。

3. **新建符号**：`File → New Symbol`，弹窗填写：
   - Symbol name（符号名）：`HT16C21A-28SSOP`
   - Reference designator（位号前缀）：`U`
   - Number of units：`1`（单封装）
   - 其余留空。

4. **画外形**：右侧工具栏 `Add a rectangle`，画芯片框（约 800 mil 宽 × 2200 mil 高，可按引脚数量微调）。

5. **添加引脚**：快捷键 `P`（或右侧 `Add a pin`），逐个放置。每个引脚：
   - Pin name = 数据手册引脚名（如 `SEG19/VLCD`）
   - Pin number = 数据手册引脚号（1–28）
   - Electrical type = 上表对应值
   - **引脚间距（相邻引脚中心距）用 100 mil（2.54 mm）**：KiCad 符号编辑器默认网格是 50 mil，即每 2 格放一个引脚。100 mil 是标准库通用值，名字不会挤在一起；不要用 200 mil（太稀）。
   - **引脚长度**（引脚伸出的线段长）默认 100 mil，与「间距」是两回事，保持默认即可。
   - 放置后可用 `R` 旋转、`X`/`Y` 镜像调整朝向。

6. **分组布局**：按第 2 节示意，左列放脚 1–8，右列放脚 9–28。

7. **含 `/` 的引脚名**：直接填 `COM4/SEG0`、`SEG19/VLCD` 即可，KiCad 支持 `/`。若想只显示其中一个名字，可用 `~{...}` 隐藏：如 `SEG19~{/VLCD}`（`~{...}` 内的内容不显示）。可选。

8. **保存**：`Ctrl+S`，关闭 Symbol Editor。

9. **在原理图使用**：
   - 原理图编辑器 `Place → Add Symbol`（快捷键 `A`），选择库里的 `HT16C21A-28SSOP` 放置。
   - 若原理图看不到该库，先 `Preferences → Manage Symbol Libraries` 把该 `.kicad_sym` 加进项目。

10. **关联封装（可选，也可 PCB 阶段再做）**：在符号属性里 Footprint 字段填 `Package_SO:SSOP-28_3.9x9.9mm_P0.635mm`（见 §9，已核对数据手册第 34 页，是精确匹配）。

## 5. 备注（数据手册要点，供原理图/固件参考）

- **I²C 地址**：7-bit 从机地址 `0x38`（写 `0x70` / 读 `0x71`），见数据手册「从机寻址」。
- **SEG19/VLCD 双功能**：内部电压调整（IVA）使能时作 VLCD 电压检测；或外接电阻决定 VLCD 偏置，详见数据手册「SEG/VLCD 共用引脚和内部电压调整设置」。
- **供电电流**：约 18 μA；VDD 旁加 100 nF 去耦，与 nRF52810、SHT40 共用 3 V VDD。
- **驱动模式**：Bias 1/3 或 1/4、Duty 1/4 或 1/8（20×4 或 16×8），帧频率 80 Hz 或 160 Hz。

## 6. 原理图接线（Eeschema）

> 参考数据手册第 23–25 页「电源电压供应顺序 / 应用电路」。项目背景：HT16C21A 与 nRF52810、SHT40 共用 3 V（CR2032 直供）；I²C 复用 SHT40 已有的总线（nRF52810 的 P0.06=SDA、P0.07=SCL，见 `引脚分配_nRF52810_QFN48_方案AB.md`）。

### 6.1 接线总览（网络表）

| 网络名 | HT16C21A 引脚 | 还要接到 |
|--------|--------------|---------|
| `+3V`（VDD） | 1 VDD | nRF52810 VDD、SHT40 VDD、上拉电阻、去耦电容 |
| `GND` | 4 VSS | nRF52810 VSS、SHT40 VSS、去耦电容 |
| `I2C_SDA` | 2 SDA | nRF52810 P0.06、SHT40 SDA、上拉到 `+3V`（10 kΩ 或 4.7 kΩ 均可） |
| `I2C_SCL` | 3 SCL | nRF52810 P0.07、SHT40 SCL、上拉到 `+3V`（10 kΩ 或 4.7 kΩ 均可） |
| `LCD_COM0–3` | 5–8 COM0–COM3 | LCD 玻璃 COM 端 |
| `LCD_SEG*` | 9–28（含复用脚） | LCD 玻璃 SEG 端 |

### 6.2 逐类接线

**① 电源**
- `VDD`(1) → `+3V`；VDD 脚旁就近放 **100 nF（0.1 µF）去耦到 GND**（数据手册应用电路即 0.1 µF）。
- `VSS`(4) → `GND`。
- 与 nRF52810、SHT40 共用 3 V，不再另加稳压。

**② I²C 总线**
- `SDA`(2) → `I2C_SDA`，`SCL`(3) → `I2C_SCL`，与 SHT40 并到同一条总线。
- 上拉：`I2C_SDA`、`I2C_SCL` **各一对到 `+3V`**，**整条总线只放一对**，别每个器件各放一套。阻值 **10 kΩ 或 4.7 kΩ 均可**：4.7 kΩ 只是 HT16C21A 数据手册的「典型值」示例，不是硬性要求；SHT40 只要求 Rp ≥ 390 Ω 下限（VDD≥1.62 V）。本项目 100 kHz 低速、两从机总线电容小（约 20–50 pF，10 kΩ 上升时间 ≈ 500 ns < 1000 ns 规格），**沿用 SHT40 侧的 10 kΩ 即可，功耗还更低**。
- 地址不冲突：HT16C21A = `0x38`，SHT40 = `0x44`。
- **总线速率必须用 100 kHz 标准模式（不能用 400 kHz）**：HT16C21A 的 I²C 在 VDD=2.4–5.5 V 只保证 100 kHz，仅当 VDD≥3.0 V 才支持 400 kHz（数据手册「交流电气特性–I²C 接口」）。CR2032 直供电压会随放电跌到 3 V 以下，所以 400 kHz 不可靠；nRF52810 的 TWIM 频率设为 `K100`。

**③ LCD 玻璃（COM / SEG）**——选哪种模式由最终 LCD 玻璃的 COM/SEG 数和引脚映射决定：

| 模式 | COM 端 | SEG 端 |
|------|--------|--------|
| 20×4（20 SEG × 4 COM） | 脚 5–8 = COM0–3 | 脚 9–12 复用脚作 SEG0–3，脚 13–28 作 SEG4–19 |
| 16×8（16 SEG × 8 COM） | 脚 5–12 = COM0–7 | 脚 13–28 作 SEG4–19（16 个） |

**④ 脚 28（SEG19/VLCD）双功能**——二选一：

- **推荐：作 SEG19 用**。内部电压调整（IVA）除能时，VLCD 偏置由内部 VDD 提供，**无需外接 VLCD 电阻**，接线最简单。
- 备选：作 VLCD 用。若 LCD 玻璃需要特定 VLCD 电压，在 `VLCD` 与 `VDD` 之间**外接电阻 VR** 决定偏置（此时少一个 SEG，SEG 只到 18）；若 IVA 使能，VLCD 作电压检测脚、外部不供电。

**⑤ 电源时序**：本设计 VLCD 由 VDD 派生（内部或经电阻），上电自然满足 Holtek「先 VDD 后 VLCD」要求，**无需额外时序电路**。只有 VLCD 单独接外部电源时才需要遵守该时序。

### 6.3 Eeschema 操作要点

1. `Place → Add Symbol`（`A`）放 `HT16C21A-28SSOP`，连同 nRF52810、SHT40 符号。
2. **推荐用网络标签（Net Label，`L`）而不是拉长线**：给 I²C、电源打上 `I2C_SDA` / `I2C_SCL` / `+3V` / `GND` 标签；COM/SEG 脚尤其适合用标签，再集中引到 LCD 玻璃连接器 / 焊盘。
3. 去耦、上拉：放 `Device:C`（100 nF）、`Device:R`（4.7 kΩ），赋好值与封装。
4. 电源符号用 `power:GND`、`power:+3V3`（或自建 `+3V`）接 VDD/VSS。
5. 若 LCD 玻璃型号未定，COM/SEG 先挂标签占位；最终必须接全，否则 ERC 报未连接（确实不接的脚放 No-Connect 叉号 `X`）。
6. 完成后 `Inspect → Electrical Rules Check` 跑 ERC，确认无错误。

### 6.4 首版原理图推荐默认配置

- 20×4 模式，脚 28 作 **SEG19**，IVA 除能（VLCD 由内部 VDD 提供）。
- 上拉 10 kΩ × 2（沿用 SHT40 现有值，4.7 kΩ 也可）+ 去耦 100 nF × 1。
- I²C 复用 SHT40 总线的 P0.06/P0.07，地址 0x38 / 0x44 不冲突。
- I²C 总线速率 **100 kHz 标准模式**（HT16C21A 全电压范围只保证 100 kHz，见 §6.2）。

## 7. LCD 玻璃（段码屏）在 KiCad 里怎么表示

**结论：段码 LCD 玻璃可以、也应该建成符号，不是「没法建」。** 每个段码本质是 COM 电极与 SEG 电极之间的小电容，玻璃上有真实电气引脚（COM0–3、SEG0–19），所以它就是一个无源器件，和 HT16C21A 一样按引脚建符号。

### 7.2 怎么接（对好引脚号 + 标签一致）

- HT16C21A 的 COM/SEG 与玻璃符号同名引脚一一对接（用网络标签，见 §6.3）：
  - 驱动 `COM0`（脚 5）↔ 玻璃 `COM0` … `COM3`（脚 8）↔ 玻璃 `COM3`
  - 20×4 模式：驱动脚 9–12（复用脚作 SEG0–3）+ 脚 13–28（SEG4–19）↔ 玻璃 `SEG0`–`SEG19`
- **关键：网络标签靠「文字完全一致」才相连**——驱动脚和玻璃脚必须放**完全相同**的标签（如都写 `COM0`），才会连成同一网络；一个写 `COM0`、一个写 `LCD_COM0` 是不相连的。标签名直接用 `COM0`–`COM3`、`SEG0`–`SEG19`，与两符号引脚同名最省事。
- 全部 24 脚都用（20×4 + 脚 28 作 SEG19），所以**不用画 X**；ERC 也不会报「未连接」。

### 7.3 什么时候才画「X」
- **只有真正不接的引脚才放 No-Connect（X）**，例如：
  - 脚 28 选作 VLCD 时 SEG19 被占用 → 该脚及玻璃对应 SEG 放 X；
  - 玻璃用不到的多余 SEG（如玻璃只需 16 个 SEG）→ 多余的 SEG 脚放 X。
- **正常情况 COM/SEG 全部接到玻璃，一个 X 都不用画。全画 X 是错的**——那会让 ERC 认为这些脚悬空，与实际（接到玻璃）不符。

### 7.4 玻璃的 footprint（封装）
- 玻璃本体通过斑马条（zebra/elastomeric）、FPC 或直接焊盘连接，机械结构取决于最终玻璃型号。
- 完整封装做法见 **§9.2**（HT16C21A 见 §9.1）。玻璃封装 = 玻璃外形 + 一排连接焊盘，属自定义 footprint，需在 Footprint Editor 里建。

## 8. 玻璃选型例子（本项目）

### 8.1 结论：用 20×4 模式（不用 16×8）

显示内容与段数预算：

| 内容 | 段数 |
|---|---|
| 温度 3 位（7 段 × 3） | 21 |
| 湿度 3 位（7 段 × 3） | 21 |
| °C / % 符号 | 2–4 |
| 负号、小数点 | 3 |
| 电量条图标 | 4 |
| 低电 / BLE 图标 | 2–3 |
| **合计** | **约 55 段** |

- 20×4 = 80 段（20 SEG × 4 COM），够用且留约 25 段余量；16×8 = 128 段，用不到一半，玻璃更复杂更贵。
- HT16C21A 20×4 模式脚位：SEG0–3 = 脚 9–12（复用脚），SEG4–19 = 脚 13–28，COM0–3 = 脚 5–8，共 24 脚。

### 8.2 量产：定制玻璃（推荐，这是最终方案）

「温度 + 湿度 + 电量 + °C/% 图标」这种组合图案没有现成玻璃，需发图纸开模定制。发给玻璃厂的规格单：

| 参数 | 值 |
|---|---|
| 显示类型 | TN 正显 / FSTN（反射式，无背光） |
| 驱动方式 | 1/4 Duty、1/3 Bias（对应 20×4 模式） |
| VLCD 工作电压 | 3.0 V |
| COM / SEG | 4 COM × 20 SEG = 80 段 |
| 显示内容 | 3 位温度（负号+小数点+°C）、3 位湿度（小数点+%）、电量条、低电/BLE 图标 |
| 连接 | 金属引脚（或 FPC / 斑马条） |
| 外形 / 视窗尺寸 | 28.0 × 20.0 mm 外形 / 24.0 × 16.0 mm 视窗（详见 §7.1） |
| 工作温度 | −20 ~ +70 ℃ |
| 数量 | 量产 1000+；打样先做 10–20 片 |

成本量级：开模费约 ¥1000–3000（一次性）+ 单价 ¥2–10/片 + MOQ 1000–3000 片。供应商：Orient Display 或深圳/东莞段码厂（1688/阿里搜「段码 LCD 定制」）。

### 8.3 原型：现成替代品（先验证驱动链，别被定制周期卡进度）

| 型号 | 说明 | 价格 | 注意 |
|---|---|---|---|
| Orient Display OD-409（DigiKey 5491-OD-409-ND） | 4 位 7 段 TN 玻璃 | ~$10.76 | 5 V 驱动、只有 4 位数字 |
| Microhello EDS811 | 4½ 位 7 段 TN | $4.65 | 5 V |
| ETON ET-1866 | 4 位 7 段，1/4 Duty 1/3 Bias | €1.4–2.1 | 驱动方式正对 20×4 |

**⚠️ 3 V 提醒**：现成段码玻璃多为 5 V 规格，CR2032 直供 3 V、HT16C21A 的 VLCD 上限 = VDD = 3 V，5 V 玻璃直驱对比度会很淡。原型要订 **3 V 版本**，或用「带 HT1621/HT16C21 驱动的段码模块」（淘宝/LCSC 搜「段码 LCD 模块」）先调通 I²C 与固件。

### 8.4 落地建议

1. 原理图按 **20×4 + 定制玻璃** 画（COM/SEG 挂标签占位，见 §6–§7）。
2. 并行：① 画玻璃段位图发厂打样；② 先买现成段码模块或 3 V 4 位玻璃验证 HT16C21A 驱动，等定制玻璃回来再换。

## 9. 封装（Footprint）怎么解决

两个器件的封装性质完全不同，分开处理：

| 器件 | 封装类型 | 做法 |
|---|---|---|
| HT16C21A-28SSOP | 标准 SSOP-28 | **直接调 KiCad 官方库，已核对是精确匹配**（§9.1） |
| LCD 段码玻璃 | 自定义（玻璃 + 连接焊盘） | **Footprint Editor 自建**，尺寸/脚距等玻璃厂「段位图」定（§9.2） |

### 9.1 HT16C21A-28SSOP：直接用官方库封装

**封装名：`Package_SO:SSOP-28_3.9x9.9mm_P0.635mm`**（KiCad 10.0 已带，无需自建）。

数据手册第 34 页「28-pin SSOP (150mil) 外形尺寸」逐项核对：

| 参数 | 数据手册 (mm) | KiCad 封装 | 结论 |
|---|---|---|---|
| 封装体宽 B | 3.90 BSC（150 mil） | 3.9 mm | ✅ |
| 封装体长 C′ | 9.90 BSC | 9.9 mm | ✅ |
| 引脚间距 E | 0.635 BSC（25 mil） | P0.635mm | ✅ |
| 引脚宽 C | 0.20–0.30 | 焊盘宽 0.4 mm | ✅ 够盖住引脚 |
| 引脚长 G | 0.41–1.27 | 焊盘长 1.2 mm | ✅ |
| 封装体厚 D | max 1.75 | — | ✅ 无底板 |
| 含引脚总宽 A | 6.00 BSC | 跨距 5.2 mm | ✅ |

- 焊盘：28 个 SMD，1.2 × 0.4 mm，左右各 14 脚；带丝印、阻焊、锡膏层，还带 3D STEP 模型（`SSOP-28_3.9x9.9mm_P0.635mm.step`）。
- 脚序：pin 1（VDD）在左上，逆时针 1→28（与数据手册「VDD 1 … SEG19/VLCD 28」一致）。

**关联方法（两种任选）**：
1. **符号属性直接填**：符号编辑器中给 `HT16C21A-28SSOP` 的 Footprint 字段填 `Package_SO:SSOP-28_3.9x9.9mm_P0.635mm`（见 §3 步骤 10）。
2. **PCB 阶段再关联**：`Tools → Assign Footprints`（CvPcb）里，按 `Reference=Ux`、`Value=HT16C21A` 过滤后指定该封装。

> ⚠️ 别用 `SSOP-28_5.3x10.2mm_P0.65mm`——那是 5.3 mm 宽体（210 mil）的另一规格，脚距也对不上（0.65 vs 0.635 mm）。本项目锁定 150 mil 窄体，只能用 `3.9x9.9mm_P0.635mm`。
>
> 💡 省事捷径：LCSC C5444716 有现成 KiCad 符号+封装可下载，可直接 import 整套（连符号都不用建）。但既然符号已按 §3 建好，这里只需补这一个封装名。

### 9.2 LCD 玻璃：自建封装（玻璃外形 + 连接焊盘）

段码玻璃不是标准器件，KiCad 官方库没有。它的封装 = **两样东西叠在一起**：

1. **玻璃外形**（Fab + 丝印层画 28 × 20 mm 框，标出 24 × 16 mm 视窗）——纯机械，占位/摆件用，也提示装配和避让。
2. **一排连接焊盘**（24 个，对应 4 COM + 20 SEG）——电气连接，脚距和排列由玻璃厂「段位图」定。

#### 9.2.1 连接方式决定焊盘形式（先选一种）

| 连接方式 | 说明 | 脚距 | 适合阶段 | 焊盘形式 |
|---|---|---|---|---|
| **斑马条**（zebra/导电橡胶） | 玻璃边 ITO 触点 ↔ PCB 焊盘，靠结构件压紧 | 0.4–1.0 mm | **打样/小批量首选**，零焊接、零开模 | SMD 矩形焊盘一排 |
| **FPC + 热压**（ACF/hot-bar） | 柔性排线热压到玻璃 | 0.5 mm 常见 | 量产，连接可靠 | SMD 焊盘 + 定位 |
| **金属引脚** | 玻璃引出金属针，直插/贴片 | ≥ 2.0 mm | 手焊验证 | 通孔或 SMD 焊盘 |

**本项目推荐：斑马条打样、FPC 量产**。理由：24 脚全在 28 mm 短边，脚距 ≈ 28/23 ≈ 1.2 mm，金属引脚（≥2 mm）塞不下；斑马条免焊接、玻璃厂基本都支持，是最省事的打样连接方式。

#### 9.2.2 自建封装步骤（Footprint Editor）

| 步骤 | 操作 | 关键点 / 值 |
|---|---|---|
| 1 | 打开 Footprint Editor | 原理图/PCB 菜单 `Tools → Footprint Editor` |
| 2 | 建库 | `File → New Library`，命名 `LCD.pretty`（项目库） |
| 3 | 新建封装 | `File → New Footprint`，名称 `LCD_Segment_20x4` |
| 4 | 画玻璃外形 | Fab 层 `Add rectangle`：28.0 × 20.0 mm；丝印层再画一圈外框 |
| 5 | 画视窗（可选） | Fab 层画 24.0 × 16.0 mm 虚线/细框，标在玻璃中间 |
| 6 | 加焊盘 | 快捷键 `P`，放 **24 个 SMD 焊盘**，沿底边（连接边）排一排 |
| 7 | 焊盘参数 | 尺寸 ~1.5 × 0.6 mm；脚距 = 玻璃厂段位图给的脚距（**先按 1.0 mm 占位**，拿到图再改） |
| 8 | 焊盘编号 | 1–24，**与符号引脚号一一对应**（见下） |
| 9 | 加 Courtyard | 比玻璃外形外扩 0.25 mm，避免与相邻器件干涉 |
| 10 | 保存 | Ctrl+S |

布局示意（玻璃框 + 底边 24 焊盘，脚距占位 1.0 mm）：

```
┌────────────────────────────────┐
│                                │
│   ┌────────────────────────┐   │   ← 视窗 24×16
│   │                        │   │
│   └────────────────────────┘   │
│                                │   ← 玻璃外形 28×20
│ ▢ ▢ ▢ ▢ ▢ ▢ … ▢ ▢ ▢ ▢ ▢ ▢ ▢ │   ← 24 焊盘一排（COM0–3 + SEG0–19）
└────────────────────────────────┘
```

#### 9.2.3 焊盘编号必须跟符号对齐（最重要）

- 符号 `LCD_Segment_20x4` 的脚 1–24 已经定为 COM0–3、SEG0–19（§7.1 表）。netlist 靠**脚号**把符号脚连到封装焊盘，所以：
  - **封装焊盘 1 必须物理上是玻璃的 COM0 脚**，焊盘 2 = COM1 … 焊盘 24 = SEG19。
- 但玻璃的真实脚序（哪个物理脚是 COM0、哪个是 SEG0）**只有玻璃厂段位图知道**，不同玻璃布局不一样。
- 所以流程是：**先按逻辑顺序放 24 个焊盘占位 → 拿到段位图后，按图上 COM/SEG 的实际物理顺序重排焊盘编号**（或重排符号引脚号，二选一，别两边都改）。

> 在拿到段位图前，也可以先用官方库的 `Connector_PinHeader_2.54mm:PinHeader_1x24_P2.54mm_Vertical` 之类占位，等玻璃定了再换成自建封装。但 24 脚 2.54 mm 排开有 58 mm 长，比玻璃还宽，仅作临时占位、不用于打板。

#### 9.2.4 拿到段位图后的收尾动作

1. 用段位图的真实脚距、焊盘尺寸、脚序，改 §9.2.2 的自建封装（或直接建最终版）。
2. 核对 24 个焊盘编号 ↔ 玻璃 COM/SEG 物理脚一一对应。
3. 原理图里 `LCD_Segment_20x4` 的 Footprint 字段填 `LCD:LCD_Segment_20x4`。
4. 跑 `Tools → Assign Footprints` 确认无「未分配封装」。
