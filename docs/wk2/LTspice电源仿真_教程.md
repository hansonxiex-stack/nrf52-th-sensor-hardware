# LTspice 电源仿真 · 详细 GUI 搭建（CR2032 供电轨）

> 第 2 周交付物「LTspice 电源仿真」。只做电源：验证 CR2032 直供 3V 时，nRF52810 发射浪涌会不会把 VDD 拉到 1.7V 欠压线以下。
> 本文件 = **GUI 手搭**的完整步骤，数值全部按 `正式工程_方案B` 原理图网表逐脚核对过。

---

## 0. 先确认：要仿真的电路长这样（已核对网表）

```
CR2032(3V + 内阻Rbat)
   │
   ├─ C1  2.2uF ─┤
   ├─ C4  100n  ─┤
   ├─ C12 100n  ─┤  ← VDD 轨上共 6 个电容(2.2u + 100n×5)
   ├─ C17 100n  ─┤
   ├─ C18 100n  ─┤
   ├─ C19 100n  ─┤
   ├─ I_nRF  (2uA→10mA)   ← nRF52810(含LED)
   ├─ I_SHT  (0.2uA→0.6mA) ← SHT40
   └─ I_HT   (18uA 恒定)   ← HT16C21A + LCD玻璃
   │
  GND
```

- **VDD 轨电容 6 个**：C1=2.2µF + C4/C12/C17/C18/C19=100nF×5（C17/C18/C19 就是 nRF 三个 VDD 脚的 3 个 100n）。
- **负载 3 个 IC**：nRF52810、SHT40、HT16C21A。LCD 玻璃由 HT16C21A 驱动，不单独挂 VDD。
- nRF52810 内部稳压那几颗（C5 100p、C7 100n、C11 1µF，在 DEC/DCC 脚上）**不进这个仿真**——属于 nRF 芯片内部，已抽象进「10mA 负载电流」。

---

## 1. 建原理图 + 放元件

打开 LTspice → `File → New Schematic`（左上角白纸图标）。

放元件：按 `F2`（或点「Component」门图标）→ 输名字 → 放置 → `Esc` 退出。

| # | 元件 | F2 搜的名字 | 数量 | 值怎么填 |
|---|---|---|---|---|
| 1 | 电压源（电池） | `voltage` | 1 | 右键 → **DC value[V]** 填 `3` |
| 2 | 电阻（内阻） | `res` | 1 | 右键 → **Resistance** 填 `15` |
| 3 | 电容 | `cap` | 6 | 右键 → **Capacitance** 分别填 `2.2u`、`100n`、`100n`、`100n`、`100n`、`100n` |
| 4 | 电流源（负载） | `current` | 3 | 见下 |
| 5 | 地 | `gnd`（或按 `G`） | 1 | — |

**3 个电流源（最容易错）**——右键电流源 → 点 **`Advanced`** → 函数下拉选 **`PULSE(I1 I2 Tdelay Trise Tfall Ton Tperiod)`** → 把 6 个参数改成：

| 电流源 | I1(低) | I2(高) | Tdelay | Trise | Tfall | Ton | Tperiod |
|---|---|---|---|---|---|---|---|
| `I_nRF`（nRF52810） | `2u` | `10m` | `0.2` | `1u` | `1u` | `10m` | `1` |
| `I_SHT`（SHT40） | `0.2u` | `0.6m` | `0.3` | `1u` | `1u` | `10m` | `2` |
| `I_HT`（HT16C21A） | 这个**不用 PULSE**，恒定值：右键直接填 **DC value = `18u`** |

> 单位：`u`=µA、`m`=mA。I_nRF：睡眠 2µA，每 1 秒发射一次、持续 10ms、峰值 10mA。

---

## 2. 连线（`F3`）

1. **电压源 `+` → 电阻一端**；电阻另一端就是 **VDD 轨**。
2. **6 个电容**全部一端接 VDD 轨、一端接地。
3. **3 个电流源**：让电流**从 VDD 轨流向地**——源的有圈那端（正端）接 VDD 轨、另一端接地。
4. 电压源 `−` 端接地。

交叉点要有**圆点**才接通，没圆点就是没连上。`F3` 拖线，`Esc` 结束。

> 给节点起名：鼠标放到 VDD 轨线上 → `F4`（右键 → Label Net）→ 填 `VRAIL`，波形就会显示 `V(vrail)`。

---

## 3. 加指令 + 跑

1. 按 `S`（或最右侧 `.op` 图标）→ 输入 `.tran 0 2 0 10u` → 回车 → 放空白处。
2. 点**小人图标**（`Ctrl+R`）→ 跑。
3. 波形窗口里，把鼠标移到 VDD 轨线上（变红色电压探针）→ 点一下 → 出 `V(vrail)`。

---

## 4. 看结果

波形是 3V 附近一条线，每 1 秒一个向下「凹口」（发射 10ms）。**看凹口最低点**，和 1.7V 比：

| 电池内阻 Rbat | 谷底 | 结论 |
|---|---|---|
| 15Ω（半新，默认） | ≈ 3.0 − 10mA×15Ω = **2.85V** | ✅ |
| 10Ω（新） | ≈ 2.90V | ✅ |
| 50Ω（快没电） | ≈ 2.50V | ✅ |

**结论：全程最低 ~2.5V，离 1.7V 差得远，CR2032 直供对 nRF52810 欠压余量足够。**

> ⚠️ 更紧的约束别忘：I²C 400kHz 和 LCD 的 VLCD 都要 ≥3.0V，而 CR2032 放电会跌破 3V——已在原理图用「I²C 100kHz + VLCD 内部派生」解决。本仿真只证明「不破 1.7V」。

---

## 5. 进阶：扫三种电池电量

1. 电阻 `Rbat` 的值从 `15` 改成 `{Rb}`（花括号必须带）。
2. 按 `S` 加一条 `.step param Rb list 10 30 50`。
3. 重跑 → 三条 V(vrail)（10/30/50Ω）。

想测「多大电流才把 3V 拉到 1.7V」，把 `.tran` 换成：
```
Iload VRAIL 0 {I}
.step param I 0 100m 1m
.dc Iload 0 50m 0.1m
```
