# 正式工程_方案B — 叠层方案与设计规则

> 板：智能温湿度传感器（nRF52810 QFN-48 + HT16C21A SSOP-28 + SHT4x + 20×4 段码 LCD + CR2032）
> 叠层：嘉立创标准四层 1.6mm
> 最后更新：2026-09-17

---

## 0. 这份文档的作用

叠层决定了板上所有无源设计的边界条件 —— 过孔有多贵、平面隔多远、走多宽才是 50Ω、去耦电容最多能做到多好。

**第 2 节把这些数字定死，第 3 节是由此推出的规则，第 4 节是具体的落板动作。**

> ⚠️ **改叠层之前先回到第 2 节重算。** 下面每一个数都是从这一套叠层推出来的，换叠层全部作废。

## 2. 由叠层推出的关键数字

### 2.1 过孔电感

公式 `L ≈ 0.2 · h · [ln(4h/d) + 1] nH`（h、d 单位 mm，钻孔 d = 0.3mm）

| 连接 | 孔深 h | 电感 |
|---|---|---|
| F.Cu → In1.Cu（**地过孔**） | 0.2355 mm | **0.101 nH** |
| F.Cu → In2.Cu（**电源过孔**） | 1.3157 mm | **1.017 nH** |
| F.Cu → B.Cu（通孔全深） | 1.5712 mm | 1.270 nH |

**推论：**

1. **去耦电容的地过孔几乎免费（0.10 nH）。** 这个优势完全来自"In1 就在顶层下方 0.2355mm"
2. 到 In2 的电源过孔贵 10 倍（1.02 nH）—— 但它只承担**体电流补给**，不在高频环路里，所以无所谓
3. **过孔一律用通孔（F.Cu→B.Cu），不必为"只到 In1"上盲孔。** In1 以下那 1.31mm 是 stub，对地过孔无影响。嘉立创标准四层做盲孔不划算

### 2.2 平面扩展电感 —— 对数增长，几乎不涨

公式 `L ≈ (μ₀·h/2π)·ln(d/r)`，h = 0.2355mm，r = 0.15mm

| 两个过孔间距 d | 平面扩展电感 |
|---|---|
| 1 mm | 0.089 nH |
| 3 mm | 0.141 nH |
| 6 mm | 0.174 nH |
| 10 mm | 0.198 nH |

**对照：顶层 0.2mm 宽走线 = 0.30 nH/mm。**

> **1mm 顶层走线 ≈ 把地过孔挪远 10mm。**

所以：**永远优先缩短顶层走线，不要为了"让两个过孔挨近"去绕线。**

### 2.3 微带线阻抗（顶层，h = 0.2104mm，εr = 4.4）

| 线宽 | εr_eff | Z₀ |
|---|---|---|
| 0.20 mm | 3.161 | 72.8 Ω |
| 0.25 mm | 3.210 | 65.2 Ω |
| 0.30 mm | 3.254 | 59.3 Ω |
| **0.36 mm** | 3.301 | **53.6 Ω** ← 现用 |
| 0.40 mm | 3.329 | 50.4 Ω |
| 0.50 mm | 3.391 | 43.9 Ω |

- **0.36mm 标称 53.6Ω**（未计阻焊，加阻焊后约 52Ω）。嘉立创阻抗公差 ±10%，**在范围内，不用改**
- 想精确 50Ω 是 0.40mm，但没必要 —— 差 3.6Ω 的回波损耗约 −32dB，可忽略
- **0.20mm 颈缩段 = 72.8Ω**，是 50Ω 线的 1.46 倍。但只有 0.7mm 长（≈0.01λ），属"集总"范围，反射可忽略。**这是 QFN 0.4mm 间距下唯一可行的做法**

### 2.4 平面电容（In1–In2 平面电容对）

`C = ε₀·εr·A/d`，d = 1.0802mm，εr = 4.5 → **3.69 pF/cm²**

当前 40×40mm 板（16 cm²）→ **约 59 pF**，ESL ≈ 0。

> **平面电容不能代替去耦电容**（59pF vs 100nF，差 1700 倍）。但它是免费的、零电感的，高频段聊胜于无。

### 2.5 环路电感决定的自谐振频率

| 环路总电感 | 100nF 自谐振 |
|---|---|
| 0.9 nH（电容贴脚） | 16.8 MHz |
| 1.4 nH（离脚 1.5mm） | 13.5 MHz |
| 2.0 nH（离脚 3mm） | 11.3 MHz |
| 3.0 nH（离脚 6mm） | 9.2 MHz |

自谐振频率以上，电容呈感性、阻抗按 2πfL 上升。**把电容从 6mm 挪到 1mm，高频去耦能力提升约 1.8 倍。**

## 3. 设计规则

### 3.1 当前 KiCad 设置（已确认）

**Board Setup → Design Rules：**

```
min_clearance              0.1 mm
min_copper_edge_clearance  0.5 mm     ← 见 3.4
min_track_width            0.1 mm     （实际用 0.2）
min_via_diameter           0.6 mm     （实际用 0.7）
min_via_annular_width      0.2 mm     （实际 0.2）
min_through_hole_diameter  0.3 mm
min_hole_clearance         0.25 mm
min_hole_to_hole           0.25 mm
min_silk_clearance         0.0 mm
```

**Netclass：**

| 名字 | clearance | track_width | via |
|---|---|---|---|
| Default | 0.2 mm | 0.2 mm | 0.7 / 0.3 |
| RF_50R | 0.2 mm | **0.36 mm** | 0.7 / 0.3 |

**netclass_patterns（RF_50R）：** `/ANT_FEED`、`Net-(U1-ANT)`、`Net-(C13-Pad2)` ✓ 三条都在

> **0.2mm 是全局 clearance 的物理上限。** U1 是 QFN-48 / 0.4mm 间距，焊盘 0.2×0.8mm，**相邻焊盘间隙只有 0.2mm**。想更细只能用自定义 DRC 规则 + rule area，netclass 是全局的。

### 3.2 去耦规则（由 2.1 / 2.2 / 2.5 推出）

**每个 VDD 引脚配一个 100nF。优先级从高到低：**

1. **缩短"引脚 → 电容 VDD 焊盘"的顶层走线** ← 唯一真正值钱的事（0.30 nH/mm）。目标 < 1mm
2. 电容的 **GND 焊盘就近打过孔**下 In1（0.10 nH）。**不要**用顶层走线把电容的地串到芯片的 GND 焊盘上
3. **电容朝向：VDD 焊盘朝芯片。** 因为走线电感（0.30 nH/mm）远大于平面电感（对数，10mm 才 0.198 nH），把"近端"留给走线
4. **电容尺寸 0402 优先**（ESL ≈ 0.45 nH）。0603/0805 的 ESL 高 50% 以上

**高频环路（决定去耦效果的就是它）：**

```
引脚 → C.VDD → [电容] → C.GND → 地过孔 → In1 平面 → 芯片 GND 过孔 → 引脚
```

**In2（VDD）过孔不在这个环路上**，它只负责慢速补给。

### 3.3 接地规则

- **In1 是全板唯一参考平面**，保持完整，任何地方不要开不必要的洞
- 芯片下方的地过孔阵列（U1 的 EP）是**地过孔群的基准点**，去耦电容的地过孔尽量靠近它 —— 但按 2.2，这条是次要的，**别为它牺牲走线长度**
- DEC 电容（C5 / C7 / C11）、晶振负载电容（C15 / C16）的地同理：就近打过孔，**紧邻芯片**
- **星形接地 / 隔离地在去耦上是错的。** 去耦电容的地必须和它服务的芯片是同一个平面、就近的位置

### 3.4 铜到板边

**规则值 0.5mm**（KiCad 默认）。嘉立创最小可做到 0.2mm 左右，但 0.5mm 给铣边公差留了余量，**保持不动**。

### 3.5 天线禁布区

四层 keepout（F.Cu / B.Cu / In1.Cu / In2.Cu）：

```
(tracks not_allowed) (vias not_allowed) (pads not_allowed)
(copperpour not_allowed) (footprints allowed)
```

轮廓：`(137.8, 50.2) → (153.6, 50.2) → (153.6, 55.8) → (149.6, 55.8) → (149.6, 56.6) → (137.8, 56.6)`

> **这是 TI SWRA117D IFA 天线的硬要求，四层都不能有铜。**
> `footprints allowed` 是必需的 —— AE1 本体（天线辐射体本身是 F.Cu 图形）要放得进去。

### 3.6 传感器热隔离（SHT4x / U2）

**数据手册的明文要求** —— SHT4x Datasheet v7.3 **§5.3 Land Pattern（第 16 页）**：

> "Soldering of the central die pad, as well as an exposed copper pad underneath it, is not recommended by Sensirion due to **it acting as a heat sink** which prevents the heater from functioning according to its specifications."

Figure 17 图注原文：

> **"There shall be no copper under the sensor other than at the pin pads."**

即：**传感器下方除引脚焊盘外不得有铜 —— 所有层。**

**现状不满足：** U2 内嵌的 keepout 只有 **F.Cu**。In1（GND 平面）、In2（VDD 平面，载流、自热）、B.Cu 在传感器正下方**都是满铜**。

**为什么必须是所有层**：铜导热系数 ≈ **385 W/(m·K)**，FR4 ≈ **0.3 W/(m·K)** —— 铜是 FR4 的 **约 1300 倍**。内层平面不只是"下面的铜"，它把传感器和整块板热耦合在一起，**热沉效应比表层铜更强**。去掉铜之后，剩下的 FR4 本身就是很好的隔热层。

**不需要开槽。** 数据手册没提开槽；而且 **SHT4x 的感湿开孔在顶面**，底部开槽对湿度测量没有帮助。

**附：禁铜 vs 开槽（routed cutout）**

| | 禁铜（keepout） | 开槽（routed cutout） |
|---|---|---|
| 切断什么 | 铜的导热路径 | 铜 + **FR4 本体**的导热路径 |
| 数据手册 | **明文要求**（§5.3） | **未提及** |
| 对湿度测量 | 不适用 | **无帮助**（感湿孔在顶面） |
| 成本 | 0 | 多一道铣槽工序 |
| 机械强度 | 无影响 | 削弱板子；焊盘悬在槽边，传感器承机械应力 |
| 嘉立创 | 免费 | 内槽支持，**最小槽宽约 1.0mm** |

铜的导热系数是 FR4 的 **约 1300 倍** —— **把铜去掉就等于切断了绝大部分导热路径**，剩下的 FR4 本身就是隔热层。开槽的边际收益很小，却要付出上面那些代价。

**什么时候才考虑开槽**：传感器旁边就有 LDO / MCU 之类热源、需要极限热隔离时。但那种情况下**首先该做的是把传感器挪远**，不是开槽。

> 如果确实要做：KiCad 里在 **Edge.Cuts** 层画一个**闭合图形**（完全在板框内、不与板框相连）即为内槽；槽壁同样受 `min_copper_edge_clearance` 0.5mm 约束。但注意 **U2 焊盘之间只有 0.9mm 净空**（焊盘在 ±0.7 / ±0.4，尺寸 0.5×0.3），**正下方做不到 1.0mm 的槽**，只能做成两侧开槽的"舌片"结构。

## 4. 具体落板动作

### P1 · 必改 —— C12 违反铜到板边规则

```
C12  @(150.350, 89.200)   0805
  pad 铜皮下沿  y = 89.92
  板框下沿      y = 90.25
  实际间距      0.325 mm      <  规则 0.5 mm    ✗
```

**约束：** C12 被夹在 U2 courtyard（下沿 87.75）和板框（90.25）之间，只有 **0.73mm** 活动空间。

**做法（二选一）：**

- **(a) U2 + C12 一起北移 0.5 ~ 1mm** —— 最简单。改完 C12 到板边 0.83mm ✓
- **(b) C12 挪到 U2 侧面** —— 东边 x > 152 或西边 x < 148.5 都空着

**检查点：** C12 的两个焊盘都要满足，pad1(VDD) 和 pad2(GND) 离板边一样近。

### P2 · 建议 —— U1 的 pad 36 没有就近去耦

```
U1.pad36  VDD  @(147.600, 64.450)      ← 北侧最西端
   最近的 C17  →  6.02 mm    （环路约 3nH，自谐振 9.2 MHz）
        C18  →  8.37 mm
对照：C17 → pad48 = 1.62mm ✓      C18 → pad13 = 1.45mm ✓
```

pad 13 和 pad 48 都配上了，**唯独 pad 36 最近的电容在 6mm 外**。

**做法：** 从板外的 C4 / C19 里挪一个 100nF 过来，放在这块空位：

```
x  145.6 ~ 147.9      y  62.2 ~ 64.0
（北边是 Y1 courtyard，到 62.20；南边是 U1 courtyard，从 64.05）
```

**要求：** VDD 焊盘朝 U1，离 pad36 < 1mm；GND 焊盘打过孔下 In1。

### P3 · 建议 —— U2 keepout 扩到四层

> **这个 keepout 是封装内嵌的，在 PCB 编辑器里点不中。**
> 它位于 `.kicad_pcb` **第 2467~2500 行**，整个落在 **U2 封装块内部**（2232~2512 行）。
> 所以点它只会选中 U2，双击出来的是**封装属性**，不是区域属性 —— 在 Zone Properties 里永远看不到它。
>
> 来源：U2 用的是系统库 `Sensor_Humidity:Sensirion_DFN-4_1.5x1.5mm_P0.8mm_SHT4x_NoCentralPad`（只读）。这个 zone 只加在了**板级实例**上，**库里没有**。

**方式 A（最快 —— 改一行）**

关闭 KiCad，把 `.kicad_pcb` **第 2468 行**：

```
			(layer "F.Cu")
```

改成：

```
			(layers "F.Cu" "B.Cu" "In1.Cu" "In2.Cu")
```

写法与天线禁布区（**第 8743 行**）完全一致。现有 polygon（1.5×1.5mm，绝对坐标 149.65~151.15 / 86.05~87.55）**不用动**。

**方式 B（图形界面）**

PCB 编辑器里右键 U2 → **在封装编辑器中打开**。在封装编辑器里 zone 就可以选中了，双击 → Layers 里勾上 In1.Cu / In2.Cu / B.Cu。
注意它是系统库、只读，保存时要"另存到"自己的库（`custom_fp.pretty`）。

**方式 C（不碰封装）**

保留封装里的 F.Cu zone（好处：跟着 U2 移动），另在板上画一个只有 In1 / In2 / B.Cu 的**板级 keepout** 盖住同一位置。
缺点：变成两个对象要同步维护，而且板级那个**不会跟着 U2 移动**。

> ⚠️ **永远不要对 U2 点"从库中更新封装"。**
> U2 的板级实例已经和系统库不一致（库里根本没有这个 zone），更新会把整个 keepout 删掉。
> 这和 **AE1** 是同一类陷阱（AE1 是因为手改了 pad 2 的环形宽度）。

**做完检查：** In1 被挖掉 1.5×1.5mm 后，周围要保留地过孔缝合，别让地平面出现孤岛。

### P4 · 顺手

| 项 | 现状 | 做法 |
|---|---|---|
| D1 pad1 | 距板边 0.700 mm | 推到 ≥ 1mm，留余量 |

## 7. 常见错误自查表

| ✗ 错误做法 | ✓ 正确做法 | 依据 |
|---|---|---|
| VDD 脚 → 过孔 → In2 → 平面上绕 → 过孔 → 回顶层 → 电容 | 引脚 → 顶层短走线 → 电容 → 电容地过孔 | §2.1 §3.2 |
| 电容的地用顶层走线串到芯片 GND 焊盘 | 电容地**就近打过孔**下 In1 | §2.2 |
| 电容 GND 焊盘朝芯片、VDD 焊盘朝外 | **VDD 焊盘朝芯片** | §2.2 |
| 为了"让两个地过孔挨近"去绕线 | 优先缩短顶层走线 | §2.2 |
| 给去耦电容单独做"隔离地" | 和芯片同一个平面、就近 | §3.3 |
| 0.36mm 不够，用 0.40mm 去追 50Ω | 0.36mm 就够（53.6Ω，±10% 内） | §2.3 |
| 天线区某一层铺上铜"问题不大" | 四层全禁 | §3.5 |
