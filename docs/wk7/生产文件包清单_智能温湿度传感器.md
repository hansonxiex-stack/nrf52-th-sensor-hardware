## 2. 逐项说明

### 2.1 Gerber（11 图层 + 作业文件）

| 项 | 内容 |
|---|---|
| 格式 | RS-274X，**关闭 X2 扩展**（`%TF` 属性仍保留以标记层功能） |
| 单位 / 坐标 | 公制，绝对坐标，4.6 格式 |
| 扩展名 | Protel 风格（`.gtl/.g1/.g2/.gbl/.gtp/.gbp/.gto/.gbo/.gts/.gbs/.gm1`），板厂 CAM 通用 |
| 极性 | 线路 / 丝印 / 钢网 / 板框为正片；**阻焊为负片**（`SolderMask`，开窗处为图形） |
| 丝印处理 | 已做**阻焊扣除**（丝印压焊盘处自动断开），线宽 0.16 mm |
| 铜箔 | 外层 1 oz（0.035 mm），内层 0.5 oz |
| 内层 | In1.GND、In2.PWR 均为**整层平面**，无走线 |

`正式工程_方案B-job.gbrjob` 汇总：`LayerNumber: 4`、`Size: 48.25 × 40.05`、`BoardThickness: 1.6062`、`ImpedanceControlled: true`。

> ⚠ **`ImpedanceControlled: true`** 是 KiCad 从板文件带出来的标记。它是"本板含阻抗控制走线"的声明，不是"要求板厂测试"；下单时**需要阻抗**一项如何选择见《PCB 打样下单说明》§3.2。

### 2.2 钻孔

```
正式工程_方案B-PTH.drl  （Excellon，公制，绝对坐标，小数格式）
    T1  0.300 mm   65 孔   过孔（ViaDrill）
    T2  0.300 mm    1 孔   AE1 天线馈点（ComponentDrill）
    T3  0.800 mm   24 孔   LCD1 段码引脚
    T4  1.500 mm    2 孔   BT1 电池座定位
    ────────────────────────
    合计            92 孔  全部镀通（PTH）

正式工程_方案B-NPTH.drl
    0 孔（本板无非镀通孔，无安装孔、无挖槽）
```

过孔全部为 **0.30 mm 孔 / 0.70 mm 盘**（环宽 0.20 mm）。其中 U1 散热盘内的 **9 个 0.30 mm 过孔为盘中孔**，需按树脂塞孔 + 电镀填平处理，见《PCB 打样下单说明》§3.3。

### 2.3 钢网（锡膏层）

钢网直接由 **`F_Paste.gtp` + `B_Paste.gbp`** 开制，不需另出一份文件。

| 项 | 内容 |
|---|---|
| 层数 | **双面**，需两张钢网（正面 28 个元件、背面 9 个元件） |
| 本板钢网尺寸 | 4.82 × 4.0 cm（与板框相同，无工艺边 → 下单时按平台自动加边） |
| 厚度 | 0.12 mm（DFM 参数快照 `stencilLayer = 4`，厚度 0.12） |
| 关键开窗 | U1 散热盘为 9 块 1.24 × 1.24 mm，每块正下方一个过孔；0402 封装面积比 1.22（> 0.66 可印刷） |

### 2.4 坐标（CPL）

| 项 | 内容 |
|---|---|
| 文件 | `CPL/CPL_SMT_智能温湿度传感器.csv` |
| 格式 | 嘉立创标准：`Designator, Mid X, Mid Y, Layer, Rotation` |
| 位号数 | **31**（正面 24 / 背面 7） |
| 单位 / 坐标 | 公制，绝对坐标，**Y 取负** |
| 坐标系 | 与 Gerber **完全一致**，无需换算（例：U1 在两者中同为 `X 149.80 / Y −67.40`） |

**31 个位号之外不贴装的 6 个**：AE1（板载 PCB 天线）、LCD1（定制 LCD 玻璃，穿孔另装）、BT1（CR2032 座，插件）、C6（NC）、C13 / C14（DNP，射频匹配预留位）。

> C6 / C13 / C14 在板文件中**未勾选 DNP 属性**，KiCad 直接导出的坐标文件会包含它们。本 CPL 已按上表剔除；**若日后重新导出坐标文件，必须同步剔除**，否则会与 BOM 不一致。
