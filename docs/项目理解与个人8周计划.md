## 一、对项目总体的理解

**项目一句话概括**：独立完成一款"高性能低功耗智能温湿度传感器"的完整 4 层板 PCB 设计，从需求调研一路做到可直接打样生产的 Gerber 文件，全程模拟专业硬件研发中心的流程与质量标准。

### 1. 项目性质

这是一个**硬件研发全流程实战项目**，不是单一环节的练习。它要求我把"原理图 → 布局 → 布线 → 验证 → 输出 → 汇报"完整走一遍，考核点明确落在四项能力上：

1. **PCB 布局布线能力**（4 层板，非入门 2 层板）
2. **信号完整性（SI）设计能力**（重点是 2.4GHz 蓝牙射频 + 晶振时钟）
3. **DFM 可制造性设计能力**（要能过嘉立创量产工艺）
4. **工程问题解决能力**（成本、功耗、阻抗、工艺之间的权衡）

### 2. 技术方案的初步推断（从项目要求中读出的选型方向）

| 模块 | 推断选型 | 说明 |
|------|---------|------|
| 主控 / 无线 | nRF52810 或 nRF52832 | Nordic 低功耗蓝牙 SoC |
| 温湿度传感器 | SHT40（SHT30/SHT45 备选） | Sensirion，I2C 接口，低功耗 |
| 电源 | ME6211 LDO（+ 可能的开关电源） | 低静态功耗，低成本 |
| 天线 | 2.4GHz PCB 天线 | 按 TI SWRA117 指南设计，需 50Ω 匹配 |
| 板框 | 36mm × 36mm（圆形/方形可选） | 4 层板 |

### 3. 贯穿始终的三条设计主线

- **电源路径**：开关电源/LDO → 滤波 → 各模块，核心是"低功耗 + 电源完整性（压降、噪声）"
- **信号路径**：SHT40 的 I2C（等长控制）+ 蓝牙射频（50Ω 阻抗受控、差分）+ 晶振时钟（最短路径）
- **约束条件**：BOM 成本 ≤ 15 元（性能与成本的权衡）+ DFM 量产可制造性

### 4. 我对"难点"的预判

- **射频阻抗匹配**：2.4GHz 蓝牙对布线要求极高，50Ω 阻抗控制 + 天线匹配网络是最大技术挑战
- **4 层叠层与电源分割**：信号-地-电源-信号的叠层如何合理利用地平面/电源平面，是区别于 2 层板的核心能力
- **成本硬约束**：15 元以内要同时满足性能、功耗、射频，选型和冗余设计都要精打细算
- **工具熟练度**：KiCad 8.0 + LTspice + FreeCAD 需要现学现用，熟练度直接决定后 7 周效率

## 二、对第一周任务的理解

第一周是「**需求分析与资料调研**」，本质是**给后 7 周打地基的认知阶段**——核心不是画板子，而是搞清楚"我要做什么、用什么做、做到什么程度"。

### 5 项工作的逐条理解

1. **竞品调研** → 明确产品定位。研究主流智能温湿度传感器规格书，产出"含 3 款竞品对比的需求分析报告"，目的是明确我们的设计取舍（为什么选 SHT40、为什么 4 层板、成本如何分配）。

2. **拆解开源 IoT 硬件设计理念 + 成本控制策略** → 理解"低功耗 + 低成本 + 可扩展"这三大开源优势在硬件层面如何落地（元器件选型、供电架构、模块化接口）。

3. **学习 KiCad 8.0 基础操作与快捷键** → 动手练一个"简单 2 层板"，把"建工程 → 原理图 → 封装/符号 → 布线 → DRC → Gerber 导出"全流程跑通，为第 2 周正式原理图热身。

4. **调研温湿度传感器芯片（SHT30/SHT40/SHT45）** → 精读数据手册，形成选型依据：测量精度、功耗电流、封装、I2C 地址与接口。

5. **调研低功耗蓝牙芯片（nRF52810/nRF52832）** → 精读技术手册，形成选型依据：功耗、外设资源、封装、成本、射频参考设计（匹配网络 + 天线）。

### 第一周交付物（3 个）

1. 产品需求分析报告（含 3 款竞品对比）
2. KiCad 基础操作练习成果（简单 2 层板）
3. 核心元器件技术手册精读笔记

### 第一周的两个要点

- **精读 ≠ 全读**：数据手册几十上百页英文，抓重点——引脚定义、典型应用电路、供电范围、功耗电流、封装尺寸，不陷进细节。
- **练习要真练完**：KiCad 2 层板必须画完并过 DRC，因为第 2 周就要用它画正式原理图，工具熟练度是后面所有周次的效率基础。

## 三、任务拆解

### 整体拆解：8 周 = 4 个阶段

| 阶段 | 周次 | 主题 | 主线 |
|------|------|------|------|
| 设计前端 | 第 1–2 周 | 调研 → 系统框图 → 原理图 → 仿真 → BOM | 把"方案"定下来 |
| 设计核心 | 第 3–5 周 | 叠层 → 布局 → 布线（高速 + 电源 + 普通） | 把"板子"画出来 |
| 验证输出 | 第 6–7 周 | DRC → SI/PI/热/DFT → DFM → Gerber/钢网/坐标/BOM | 把"生产文件"做出来 |
| 总结汇报 | 第 8 周 | 报告 + PPT + 视频 + GitHub + 答辩 | 把"成果"讲出来 |

### 第一周任务细化（可执行粒度）

**1. 竞品调研（约 2–3 天）**
- 选 3 款主流开源/商用温湿度传感器（如米家蓝牙温湿度计、Aqara 温湿度传感器、Sensirion 官方评估板等）
- 对比维度：主控/传感器选型、供电方案、板层数、尺寸、功耗、成本、天线方案
- 产出：竞品对比表 + 差异化结论

**2. 产品需求分析（约 1–2 天）**
- 定义规格：测量范围/精度、供电（电池电压）、续航目标、通信距离、成本上限 15 元
- 成本拆解：传感器 + 蓝牙 SoC + 电源 + 阻容 + PCB + 天线逐项估预算

**3. KiCad 学习（贯穿，累计约 1–2 天）**
- 装 KiCad 8.0，跑通 2 层板完整流程；整理常用快捷键；熟悉 SnapEDA 取符号/封装

**4. 芯片精读（约 2–3 天）**
- SHT40：引脚、供电、I2C 时序、典型电路、DFN 封装、功耗
- nRF52810/32：供电、GPIO、晶振、射频参考设计（匹配 + 天线）、QFN 封装、低功耗模式电流
- ME6211：输入/输出、压差、输出电流、典型电路

**5. 嘉立创工艺参数锁定（约 0.5 天）**
- 确认嘉立创 4 层板标准叠层（介质厚度、铜厚）、最小线宽/线距、最小孔径、阻抗计算参数
- 作为第 3 周叠层设计、第 4 周 50Ω 阻抗计算的输入

**6. 输出与对齐**
- 汇总 3 份交付物；周末复盘一次**选型方向与成本预算**（这是全项目的关键决策点）

### 4.3 每周理论学习明细


**第 1 周 · 传感器与无线基础（约 8 h）**
- 温湿度传感原理：电容式湿度传感、温度补偿 → 读懂 SHT40 精度/漂移指标
- I2C 总线：开漏结构、上拉电阻计算、时序、从机地址
- BLE 基础：广播 vs 连接、协议栈分层、广播间隔 → 功耗关系
- 低功耗设计概念：静态电流、占空比、休眠/唤醒
- 参考：SHT4x 数据手册、nRF52 产品规格「低功耗」章节、I2C 规范

**第 2 周 · 电源与模拟基础（约 9 h）**
- 线性稳压器原理：压差、静态电流、PSRR、输出噪声 → 读懂 ME6211 参数
- LDO vs DC-DC：效率对比、轻/重载取舍、噪声
- 去耦电容：容值选择、谐振频率、放置原则
- ESD/滤波：TVS 钳位、串联电阻、RC/LC 滤波
- 参考：ME6211 数据手册、LTspice 官方教程

**第 3 周 · 叠层设计理论（约 7 h）**
- 4 层叠层设计：信号-地-电源-信号、参考平面、对称叠层
- 嘉立创叠层参数：以第 1 周确认的介质厚度 / 铜厚为输入，计算微带线 50Ω 线宽
- 参考：IPC-2221、嘉立创阻抗计算参数、高速 PCB 布局应用笔记

**第 4 周 · 布局与回流路径（约 7 h）**
- 回流路径与环路面积：完整地平面为何重要（EMI 根源）
- 布局原则：按功能分区、热区、敏感器件远离噪声源
- 电源/地平面分割：数字/模拟/射频分区、分割与缝合
- 参考：高速 PCB 布局应用笔记、PDN 入门资料

**第 5 周 · 传输线与阻抗匹配（约 10 h，本周理论最重）**
- 传输线理论：特性阻抗 Z₀、微带线/带状线
- 阻抗匹配：为何 50Ω、π/T 型匹配网络、Smith 圆图概念
- 天线基础：PCB 天线（倒 F/蛇形）、馈电、净空区
- 晶振电路：皮尔斯振荡器、负载电容、起振条件
- 参考：TI SWRA117、Nordic nRF52 射频参考设计、KiCad 阻抗计算器

**第 6 周 · 电源完整性与 EMI（约 8 h）**
- PDN 设计：目标阻抗、去耦网络分层
- 过孔：回流过孔、缝合孔、载流能力
- EMI/EMC：辐射机理、滤波、地弹
- 参考：去耦网络应用笔记、EMC 入门资料

**第 7 周 · 信号完整性与制造工艺（约 8 h）**
- 反射与串扰：机理、端接、串扰源与抑制
- PI 分析：IR 压降、去耦谐振；热设计：热阻、散热
- PCB 制造流程：层压、钻孔、电镀、阻焊、表面处理
- DFM/DFT：线宽线距、孔径、焊盘、钢网；IPC 标准
- 参考：信号完整性教材（如 Bogatin）、嘉立创 DFM 规则、IPC 文档

**第 8 周 · 工程方法论复盘（约 6 h）**
- 全流程复盘：需求 → 原理 → 布局 → 布线 → 验证 → 生产
- 开源硬件规范：OSHWA 定义、GitHub 工程组织
- 答辩与表达：如何把工程权衡讲清楚
- 参考：OSHWA、优秀开源硬件项目
