# 本项目叠层方案——开源智能温湿度传感器（40×40mm 四层板）

> 配套：[PCB四层板叠层设计教学.md](./PCB四层板叠层设计教学.md)（先看教学再看本文件）
> 适用工程：`正式工程_方案B`（nRF52810 + SHT40 + HT16C21A + 段码 LCD + CR2032）

---

## 1. 选型结论（一句话）

采用 **S-G-P-S 叠层**：`Top(信号) / GND(地) / PWR(电源) / Bottom(信号)`，1.6mm 厚，**外层 1oz / 内层 0.5oz 铜**，用嘉立创标准四层板工艺。理由：顶层射频/晶振紧贴完整地平面控制 50Ω 阻抗，底层 I2C 紧贴电源平面，两个信号层都有参考平面。

---

## 2. 本项目叠层结构（对应嘉立创 1.6mm 标准四层）

| 层 | 层名（KiCad） | 铜/介质 | 厚度 | 本项目的用途 |
|---|---|---|---|---|
| — | F.Mask（顶层阻焊） | 阻焊油墨 | 0.01 mm | 顶层阻焊，计入总厚 |
| L1 | F.Cu（Top） | 外层 **1 oz** 铜 | 0.035 mm | 主信号层：射频、晶振、主控、传感器 |
| — | Prepreg（7628 RC49% 8.28mil） | FR-4，Er ≈ 4.4 | **0.2104 mm** | 顶层信号 → GND 的介质（阻抗关键值 H） |
| L2 | In1.GND | 内层 **0.5 oz** 铜（H/HOZ） | **0.0152 mm** | **完整地平面**（射频回流 + 数字地） |
| — | Core（1.1 mm H/HOZ） | FR-4，Er ≈ 4.5 | 1.065 mm | 中间芯板 |
| L3 | In2.PWR | 内层 **0.5 oz** 铜（H/HOZ） | **0.0152 mm** | **3V 电源平面**（VDD） |
| — | Prepreg（7628 RC49% 8.28mil） | FR-4，Er ≈ 4.4 | 0.2104 mm | 底层信号 → PWR 的介质 |
| L4 | B.Cu（Bottom） | 外层 **1 oz** 铜 | 0.035 mm | 副信号层：I2C、调试、电池、按键 |
| — | B.Mask（底层阻焊） | 阻焊油墨 | 0.01 mm | 底层阻焊，计入总厚 |
| 合计 | | | **1.606 mm**（= 铜介质 1.586 + 阻焊 0.02；嘉立创标称板厚 1.59 mm ±10%） | |

> **铜厚提醒**：嘉立创标准四层板是**外层 1 oz、内层 0.5 oz**（芯板标注 H/HOZ），不是四层都 1 oz。KiCad 物理叠层里要分开填：F.Cu / B.Cu = 0.035 mm，In1.GND / In2.PWR = 0.0152 mm。内层薄铜不影响 50Ω（参考平面电流集中在朝向走线的表面），CR2032 微安~毫安级电流下电源平面压降也可忽略。

> **总厚说明**：表中合计 1.606 mm = 铜 + 介质 1.586 mm + 上下两层阻焊（F.Mask / B.Mask，各 0.01 mm）。嘉立创下单时的「板厚 1.6 mm」指的是**不含阻焊**的基材厚度（标称 1.59 mm ±10%），阻焊另加、不在板厚里。阻抗计算只用 H（PP 0.2104 mm），与阻焊无关。

## 3. 各层信号分配与摆放建议（落到具体器件）

### 3.0 摆放总原则（先记住这 5 条）

1. **天线和射频链路**：放 Top 一条边，天线贴板边，净空区（keepout）全层挖空。
2. **关键高速件**（nRF52810、32MHz 晶振、射频 π 网络）都放 Top、紧贴 L2 完整地平面，走线最短。
3. **去耦电容永远贴着对应 IC 的电源脚**，一进（到 GND）一出（到 PWR）两个过孔，回路面积最小。
4. **发热件和温湿度传感器拉开距离**：SHT40 要远离 MCU、LED、DCDC 电感、电池这些热源。
5. **金属大件放底层反方向**：电池座、段码玻璃离天线越远越好。

```
Top（L1）元件面分区示意（40×40mm，非等比例，仅示意位置关系）：

   ┌─────────────────────────────────────┐
   │ ① 天线 AE1 + 净空区     ② 32MHz晶振(与①天线同角)    │ ← 上边
   │    (全层挖空, 贴板边)      Y1 + C9/C10    │
   │    ↓射频馈线(50Ω,0.36mm)   (贴 MCU)      │
   ├─────────────┬───────────────────────┤
   │ ③ nRF52810   │ ④ 去耦电容组            │ ← 中
   │   QFN48      │   C1/C4/C7/C17/C18/C19 │
   │   ANT脚朝天线 │   贴各自电源脚            │
   ├─────────────┼───────────────────────┤
   │ ⑤ SHT40      │ ⑥ LED + 限流电阻        │ ← 下边
   │   (靠边,远离热)│   (靠边,远离 SHT40)     │
   └─────────────┴───────────────────────┘
```

```
Bottom（L4）元件面分区示意（40×40mm，非等比例；注意与 Top 是镜像关系）：

   ┌─────────────────────────────────────┐
   │ ① CR2032 电池座 BT1    ② 按键 SW1      │ ← 一边
   │    (远离天线,居中/靠边)  (靠边好按)       │
   ├─────────────┬───────────────────────┤
   │ ③ HT16C21A   │ ④ 32.768kHz 晶振        │ ← 中
   │   28-SSOP     │   Y2 + C15/C16         │

   ├─────────────┼───────────────────────┤
   │ ⑤ 段码玻璃连接 │ ⑥ I2C 上拉 + SWD 焊盘   │ ← 另一边
   │   (金手指/斑马条)│   10k 上拉, SWDIO/CLK  │
```

### 3.1 L1 Top（主信号层）——逐件摆放

**① PCB 天线 AE1（SWRA117D）+ 净空区**
- 天线放 Top 一条边的角落，**辐射边贴板边**（天线要贴 board edge 才有好的辐射）。
- 天线正下方**所有层**（L2/L3/L4）挖空，器件、走线、过孔都不能进这个净空区。
- 净空区尺寸按 SWRA117D 应用笔记给的建议值，宁大勿小。

**② 射频 π 匹配网络（L1 3.9nH、C8 0.8pF、L3 15nH、C5 100pF、C13/C14 预留 DNP）**
- 紧挨 nRF52810 的 ANT 脚，从 ANT 脚到天线馈点走一条**直线**，全程 Top、不换层、不过孔。
- 匹配器件按「串联 → 并联 → 串联 → 并联」顺序排；并联器件（C8、C5）各自就近打一个 GND 过孔到 L2。
- 走线宽度走 RF_50R 网络类（0.36mm），两侧保持净空。

**③ nRF52810（QFN48）**
- 放 Top 中间偏天线一侧，**ANT 脚朝向天线**，让射频馈线最短。
- 晶振脚（XL1/XL2）附近预留 32MHz 晶振位置；去耦电容绕芯片四边贴着放。

**④ 32MHz 晶振 Y1 + 负载电容 C9/C10（12pF）**
- **紧贴** nRF52810 的 XL1/XL2 脚，走线最短、对称、等长，全程 Top。
- 负载电容 C9/C10 各紧贴晶振两脚，GND 端就近打过孔到 L2。
- **注意**：nRF52810 的 ANT 脚和晶振脚（XL1/XL2，连同 XL32K、DEC4）都挤在 **30–36 这一角**，晶振和射频物理上就是挨着、分不开——这是 Nordic 的标准画法。隔离**靠接地、不靠距离**：晶振周围铺地 + 一圈地过孔缝到 L2；晶振走线方向别跟射频馈线平行/交叉（馈线往板边出，晶振走线往侧向/反方向出）。

**⑤ SHT40（DFN-4）+ 100nF 去耦**
- 放 Top **靠板边**、**远离** MCU/LED/DCDC 电感/电池这些热源，让探头接触环境空气。
- 100nF 去耦贴它的 VDD 脚，I2C 脚引出 SDA/SCL。
- 若产品有外壳，SHT40 正上方要留通气孔。

**⑥ 去耦电容组（C1 2.2µF、C4/C7/C17/C18/C19 100nF、C11 1µF、C12 100nF、L2 10µH DCDC 电感）**
- 详见 §3.5 电容摆放专题。核心：**一颗电容对一颗电源脚**，贴得越近越好。

**⑦ 状态 LED + 限流电阻**
- 放 Top 靠边（好看到），**远离 SHT40**（LED 有热量和光）。

### 3.2 L2 GND（完整地平面）

- 一整层地，尽量不打碎、不切缝。
- 天线正下方挖净空，其余区域（尤其射频、晶振下方）保持连续完整。
- 板边、射频区、晶振区多打**地过孔**把 Top 的地和 L2 缝成一体（stitching via，间距 1~2mm）。

### 3.3 L3 PWR（3V 电源平面）

- VDD = 3V 单一电源平面，整层铺，不分割。
- 去耦电容的 VDD 端就近打过孔到这一层。

### 3.4 L4 Bottom（副信号层）——逐件摆放

**① CR2032 电池座 BT1**
- 放底层**离天线最远的反方向**，居中或靠一边（兼顾重量平衡）。
- 电池座金属轮廓别伸进天线净空区；VBAT/GND 走线在底层走，绕开天线正下方。

**② 按键 SW1**
- 靠板边好按，别放天线净空区。

**③ HT16C21A（28-SSOP）+ 段码玻璃**
- HT16C21A 放底层、**紧挨段码玻璃连接处**（SEG/COM 走线最短，少打 20 多个过孔）。
- 它的去耦（1µF/100nF）贴 VDD 脚，I2C 脚引出 SDA/SCL。
- 段码玻璃放底层反方向（远离天线），连接金手指/斑马条贴着 HT16C21A 排。

**④ 32.768kHz 晶振 Y2 + 负载电容 C15/C16（12pF）**
- XL32K 脚也在 30–36 这一角，和 ANT、32MHz 晶振挤在一起，Top 这一角很挤。
- 更实际的做法是**放 Bottom、放在 XL32K 脚的正下方**，用两个短过孔上去，走线短、对称、周围用地包护；若 Top 空间够，也可放 Top 贴低频晶振脚（和 32MHz 同理：靠接地隔离，走线别和射频馈线平行/交叉）。

**⑤ I2C 上拉 + SWD**
- I2C 低速（100/400kHz），哪层都能走。建议主总线在 Top 连 MCU + SHT40，到 HT16C21A 那段打一对过孔下底层；SDA/SCL 等长，10k 上拉靠近主控。
- SWD（SWDIO/SWDCLK）放底层板边，方便调试夹取；走线短，用地包护。

### 3.5 电容摆放专题（本板电容怎么摆）

**① 去耦电容（100nF 高频）——贴、近、短**

```
去耦电容的过孔接法（剖面，看 Top 上一个 100nF 去耦电容）：

  L1 Top   ─[VDD脚]──[100nF]──[GND脚]──
              │via↓              │via↓
  L2 GND   ───╪──────────────────╪───  ← 完整地平面
              │
  L3 PWR   ───╪──────────────────────  ← VDD 电源平面
              │via↑
  L4 Bottom ─────────────────────────

  · VDD 端过孔 → L3（PWR），GND 端过孔 → L2（GND）
  · 过孔紧挨焊盘（≤0.5mm），回路面积最小
  · 电容离 IC 电源脚越近越好（≤1mm 理想）
```

- 一颗 100nF 对一颗电源脚，电容离脚 ≤1mm 理想。
- VDD 端过孔 → L3，GND 端过孔 → L2，过孔紧挨焊盘。
- 别让 VDD/GND 走线绕远（回路面积越大，去耦越差）。

**② 储能大电容（2.2µF）**
- 放电源入口附近（电池 + 端进来的主干上）或 MCU 主 VDD 旁，就近补低频。

**③ 晶振负载电容（C9/C10、C15/C16 12pF）**
- 各紧贴晶振两脚，GND 端就近过孔到 L2，走线对称。

**④ 射频匹配电容/电感（C8、C5、L1、L3）**
- 按 π 网络顺序串在 ANT→天线这条直线上，并联元件就近打 GND 过孔；DNP（C13/C14）先留焊盘位置。

**⑤ DCDC 电感（L2 10µH）**
- 贴 nRF52810 的 DCDC 引脚（DCCH/DCCL），和它的去耦电容一起把环路压到最小，走线短而宽。

### 3.6 摆放完成后自查清单

- [ ] 天线净空区在所有层都空了？器件/走线/过孔都没进？
- [ ] 射频馈线全程 Top、直线、0.36mm、两侧净空？
- [ ] 每个 IC 的去耦电容都贴着对应电源脚、一进一出两个过孔？
- [ ] 32MHz 晶振贴 MCU、走线对称等长、远离射频？
- [ ] SHT40 远离热源、靠边、有空气流通？
- [ ] 电池座、段码玻璃都在底层反方向、离天线远？
- [ ] I2C SDA/SCL 等长、上拉靠近主控、不穿天线区？

## 4. 关键走线的参考平面（本项目必须盯住的 4 条）

| 走线 | 所在层 | 参考平面 | 要求 |
|---|---|---|---|
| 射频馈线（ANT→匹配→天线） | Top | GND（L2） | **50Ω 微带线**，线宽 ≈0.36mm，短而直，两侧保持净空 |
| 32MHz 晶振走线 | Top | GND（L2） | 最短、对称、等长，远离射频 |
| I2C（SDA/SCL） | Bottom | PWR（L3） | 低速不控阻抗，但要**等长**、上拉靠近主控 |
| 去耦电容 | Top | GND（L2）+ PWR（L3） | 直接贴 IC 电源脚，一个过孔到地、一个到电源 |

> 换层提醒：任何高速/射频走线若从 Top 换到别层，回流会断，要在过孔旁放一颗**地过孔**把 GND 缝回来。

## 5. 50Ω 微带线计算（本项目具体数字）

- 输入：H = 0.2104 mm（Top→GND 的 PP 厚）、Er ≈ 4.4（FR-4）、外层走线铜 1 oz、目标 50Ω ± 0.5。
- 结果：**线宽 W = 14.1 mil ≈ 0.36 mm**，反算阻值 49.84Ω（嘉立创 `JLC04161H-7628` 模板）。
- 操作：`工具 → 计算器工具 → 传输线 → 微带线`，填入后确认线宽；再在 `设计规则 → 网络类` 给 ANT 馈线网络绑这个线宽。
- **下单时勾选「阻抗控制」**，把「顶层单端 50Ω」写进工艺要求，板厂按 ±10% 修正（最终以嘉立创阻抗计算器结果为准）。

## 6. 电源 / 地分割策略

- **GND**：整层连续，不分割。天线下方挖净空，但周围仍是一整块地。
- **PWR**：单一 3V，整层铺 VDD，不分割（没有模拟/数字分压）。
- **天线净空区**：Top 的匹配网络和天线周围、以及 L2 GND 在天线正下方，都要留出净空（keepout），任何铜、走线、过孔都别进这个区。
- **地孔缝合**：板边、射频区、晶振区多打 GND 过孔，把 Top 的地和 L2 地平面缝成一体。

## 7. KiCad 落地步骤（本周 + 下周）

**第 3 周（本周，叠层 + 板框）**
1. `文件 → 板设置 → 物理叠层`：建 4 层，按 §2 填铜厚（外层 0.035 mm / 内层 0.0152 mm）与介质厚度（PP 0.2104 mm / Core 1.065 mm），命名 F.Cu / In1.GND / In2.PWR / B.Cu，并勾选 Impedance controlled。

5. 输出《叠层文档》（本文件 + 叠层截图）作为本周交付物。

7. GND、PWR 铺铜 + 地孔缝合。
