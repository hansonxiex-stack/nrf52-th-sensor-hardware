# PCB 四层板叠层设计教学（含 B 站教程）

> 用途：第 3 周「4 层叠层设计」理论学习 + 视频教程入口。
> 目标：看懂叠层为什么这么排，掌握嘉立创四层板参数，能算 50Ω 微带线线宽，并能在 KiCad 里把叠层设进去。

---

## 0. 一句话理解叠层

PCB 不是一整块板，而是**多层铜箔 + 多层绝缘介质（芯板 Core / 半固化片 Prepreg）压合**出来的「千层饼」。铜箔是走信号/电源的「导体层」，介质是夹在中间隔开它们的「绝缘层」。

「叠层设计」就是决定：**一共几层、铜和介质各多厚、哪层放信号、哪层当地、哪层当电源、信号层紧贴着哪个参考平面**。它直接决定三件事——**阻抗是否可控、EMC 是否达标、成本是否合理**。

---

## 1. 为什么四层板（对比二层板）

| 对比项 | 二层板 | 四层板 |
|---|---|---|
| 地平面 | 只能靠顶层/底层铺铜「挤」出地，被走线切得稀碎 | 有**一整层完整 GND**，回流路径最短、阻抗最低 |
| 电源 | 电源线走线，压降/噪声大 | 有**一整层 PWR**，天然低阻抗、天然去耦 |
| 射频（2.4GHz） | 很难控制 50Ω，天线性能差 | 顶层射频走线紧贴完整 GND，50Ω 好控制 |
| 成本 | 便宜 | 贵约 1.5~2 倍，但本项目必须用 |

**结论**：只要有射频（蓝牙）+ 想控阻抗 + 想压低 EMI，就得用四层板。你的项目是 nRF52810 蓝牙，所以项目要求定的是 4 层板。

---

## 2. 四层叠层的几种常见方案

| 方案 | 顺序（上→下） | 特点 | 适用 |
|---|---|---|---|
| **S-G-P-S**（信号-地-电源-信号） | Top / GND / PWR / Bottom | 顶层信号紧贴地、底层信号紧贴电源，两个信号层都有参考平面 | **最常用，本项目就用它** |
| G-S-S-P（地-信号-信号-电源） | GND / Signal / Signal / PWR | 中间两层信号互不干扰，但每个信号层只单面参考 | 高密度数字板 |
| S-S-G-P（信号-信号-地-电源） | Sig / Sig / GND / PWR | 顶层两信号层贴一起，注意串扰 | 少用 |

> 核心原则：**关键信号层一定要紧邻一个完整的参考平面（地或电源）**，两者之间介质越薄越好（薄 → 回流路径短 → EMI 小 → 阻抗好控制）。

---

## 3. 关键概念（先看懂这 5 个）

1. **Core（芯板）**：出厂就压好「铜-介质-铜」的硬板，厚度固定（如 1.2mm）。
2. **Prepreg（半固化片，PP）**：单层绝缘胶膜，压合时受热融化把各层粘在一起。外层铜和内层铜之间就是靠 PP 隔开的。
3. **参考平面（Reference Plane）**：紧邻信号层的完整铜层（地或电源）。高速信号的回流电流就贴着它走，**信号「认」的不是走线，而是它正下方/正上方的这个平面**。
4. **回流路径**：电流出去必须回来。回流路径越短、越宽、越完整，环路面积越小，辐射（EMI）越小。走线换层时回流会断，要在过孔旁加**地过孔（Stitching Via）**把地平面重新缝起来。
5. **对称叠层**：上下铜/介质尽量对称，防止压合后应力不均导致**板翘曲**（这是量产良率的大问题）。

## 4. 嘉立创标准四层板叠层参数（1.6mm）

> 以下是嘉立创四层板 1.6mm 的**典型标准叠层**，具体数值以官网「阻抗计算 / 工艺参数」页面当前数据为准。

| 层 | 材质 | 厚度 |
|---|---|---|
| L1 Top 铜 | **外层 1 oz**（35 µm） | 0.035 mm |
| 半固化片 PP（7628 RC49%） | FR-4 绝缘，Er ≈ 4.4 | **0.2104 mm** |
| L2 GND 铜 | **内层 0.5 oz**（H/HOZ） | **0.0152 mm** |
| 芯板 Core（1.1 mm H/HOZ） | FR-4，Er ≈ 4.5 | 1.065 mm |
| L3 PWR 铜 | **内层 0.5 oz**（H/HOZ） | **0.0152 mm** |
| 半固化片 PP（7628 RC49%） | FR-4 绝缘，Er ≈ 4.4 | 0.2104 mm |
| L4 Bottom 铜 | **外层 1 oz** | 0.035 mm |
| **合计** | | **1.606 mm**（标称 1.59 mm ±10%） |

> **铜厚坑点**：四层板**不是每层都 1 oz**。嘉立创标准工艺是**外层 1 oz、内层 0.5 oz**（芯板规格写作 `H/HOZ`，即两面都是半盎司铜）。在 KiCad 物理叠层里必须内外层分开填：F.Cu / B.Cu 填 0.035 mm，In1 / In2 填 0.0152 mm。填错会让叠层总厚对不上，也会让阻抗计算失去参考。

**最关键的参数**：顶层铜 → GND 层的介质厚度 **H = 0.2104 mm**（即那块 7628 半固化片），这是下面算 50Ω 微带线的输入。

---

## 5. 50Ω 阻抗与微带线

**微带线（Microstrip）**：信号走线 + 下方一个参考平面，之间隔介质。射频（蓝牙天线馈线、晶振高速走线）要按 50Ω 控制。

- 用公式/工具代入：H = 0.2104 mm、走线铜厚 1 oz（外层）、介质常数 Er ≈ 4.4，目标 50Ω。
- 结果：**线宽 W = 14.1 mil ≈ 0.36 mm**（反算阻值 49.84Ω）。
- 关键：**最终线宽要以嘉立创阻抗计算器的结果为准**（不同板厂 PP 的 Er 略有差异），并在下单时勾选「阻抗控制」，让板厂按 ±10% 帮你修正。

### 用 KiCad 自带的计算器

`工具（Tools）→ 计算器工具（Calculator Tools）→ 传输线（TransLine）→ 微带线（Microstrip）`，填入 H、Er、目标阻抗 50Ω，得到线宽。

---

## 6. 在 KiCad 里设置叠层（KiCad 7/8）

1. 打开 PCB 编辑器，`文件 → 板设置（Board Setup）`。
2. 选 **物理叠层（Physical Stackup）** 标签。
3. 把层数改成 **4**，按上面表格填各层：铜层类型（信号 / 电源）、铜厚、介质（Core/PP）厚度、介电常数 Er。
4. 命名好：`F.Cu`（Top 信号）、`In1.GND`、`In2.PWR`、`B.Cu`（Bottom 信号）。
5. 在 **设计规则（Design Rules）→ 网络类** 里给射频网络单独建一个类，绑定 50Ω 算出的线宽，布线时自动约束。

> 坑点提醒：**别用默认双层模板直接画四层板**——那样阻抗计算是失效的，必须先按上面把叠层建好再画。
