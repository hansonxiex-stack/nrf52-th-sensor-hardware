## 2. BOM 与 CPL 一致性

**一致，不涉及改板。**

- 位号集合完全相同：BOM 23 行 / 31 个贴装位号，CPL 31 行；仅 BOM 有 0 个、仅 CPL 有 0 个
- CPL 的 31 个位号逐一都能对到 BOM 中的所在行（31 / 31）
- BOM 每行的 Quantity 与该行 Designator 的个数一致（5 / 5、2 / 2、1 / 1 ……）
- 不贴装的 **AE1、LCD1、BT1、C6、C13、C14** 六项：两份文件中均不出现，符合预期
