## 使用说明

- **「变更前 → 变更后」** 只记录可核查的差异项，不含过程性调整。
- **「依据」** 一栏写明该变更的判据来源（数据手册条款 / 实测数据 / DRC 结果 / 工艺约束）。
- 涉及**库封装与板上实例不一致**的变更，详见《DRC 检查说明》与《DFM 检查报告与优化记录》。
