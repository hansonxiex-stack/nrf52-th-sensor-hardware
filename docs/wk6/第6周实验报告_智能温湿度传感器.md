## 2. 本周完成情况

### 2.1 ESD 防护器件落地（U4）★

**器件选型**：**TT0554TLX**（晶扬 JingYang，立创 C5156695），SOT-23-6L，四通道单向 TVS 阵列。

选型的第一约束不是钳位电压，而是**漏电流**——本机静态电流约 20 µA，保护器件的漏电直接吃掉续航。TT0554TLX 的漏电流**典型 0.1 µA / 最大 1.0 µA**（V_RWM = 5 V，25 °C），最坏情况占静态电流的 5%。

| 参数 | 值 |
|---|---|
| 反向工作电压 V_RWM | 5 V |
| 击穿电压 V_BR | ≥ 6.0 V |
| 钳位电压 V_C | 11 V @ 6 A |
| 结电容 | 0.3 pF（I/O–I/O）/ 0.8 pF（I/O–GND） |
| IEC 61000-4-2 | ±27 kV 空气 / ±17 kV 接触 |
| 每 I/O 耐受 | > 1000 次 ±8 kV 接触放电 |

**新建工程本地符号库。** KiCad 系统库里没有 TT0554TLX。最初借用 `Power_Protection:SRV05-4`，但两者引脚名不一致，其中 **pin 2 = GND、pin 5 = VCC** 是接线正确性的关键。本周新建 `TT0554TLX.kicad_sym` 并注册进 `sym-lib-table`，引脚名按手册改为 `I/O_1 / GND / I/O_3 / I/O_4 / VCC / I/O_2`。

> 手册没有引脚表，引脚定义用三条独立证据交叉验证：① 正文写明 *"Pin 2 … is the negative reference pin, which should connect to the GND of PCB"*；② Pin Configuration 图与 Circuit Diagram 图按 x 坐标顺序配对；③ Figure 1 中 GND / VCC 标签的实际坐标位置。三路结论一致。

**落位**：**(159.20, 62.10)，旋转 −90°，B.Cu**——与 J1 同层紧邻。

### 2.2 J1 重排与四路保护走线 ★

ESD 布局有两条硬要求：**保护器件与连接器同层**，且**"保护前路径"尽可能短**。原 J1 在 (160.20, 61.80) 旋转 180°，周边没有同层空位，于是把 J1 让到北边：

| | 变更前 | 变更后 |
|---|---|---|
| 位置 | (160.20, 61.80) | **(160.90, 55.40)** |
| 旋转 | 180° | **−90°** |

**J1 → U4 实测路径**（全程 B.Cu、0 过孔）：

| 网络 | 起点 | 终点 | 长度 |
|---|---|---|---|
| SWDIO | J1.pad2 | U4.pin1 | **3.66 mm** |
| SWDCLK | J1.pad4 | U4.pin3 | **3.83 mm** |
| RESET | J1.pad10 | U4.pin4 | **7.25 mm** |
| VDD | J1.pad1 | U4.pin5 | **15.98 mm** |

**VDD 那一路有个讲究**：J1 的 pad 1 是 VTref（调试器参考电压），几乎不走电流，所以只在 **U4 的 pin 5 紧贴处打一个过孔**接入 In2 电源平面，实测过孔 @(159.400, 64.400)、距 pin 5 焊盘 1.18 mm。

> **这个过孔必须打在 U4 之后（pin 5 一侧）**，不能打在那 15.98 mm 路径的中段——否则 ESD 电流在到达钳位点之前就经该过孔流入电源平面，等同于绕过保护器件。

**评估过又否掉的方案：把 U4 转 180°。** 转过去 VDD 可从 15.98 mm 缩到约 9.4 mm，但 U4 北排将只剩 pin 4 一个可用 I/O，SWDCLK 与 RESET 必须绕到南排，两条信号线的保护前长度从 3.83 / 7.25 mm 增至约 6.1 / 6.8 mm。

**结论是不转**：三条信号线是裸露焊盘直连 nRF52810 引脚，而 VDD 是带 2.2 µF 体电容与完整电源平面的电源轨，其瞬态能量有电容缓冲——**拿两条信号线的保护裕量去换一条电源轨的长度不划算**。

**几项值得记录的分析结论：**

**① 射频链路（SI）**　链路 13.15 mm，全程 F.Cu、**0 过孔**，线宽 0.36 mm。按叠层（介质 0.2104 mm、Er ≈ 4.4）算得 **49.8 Ω**，电长度 0.19 λ。匹配网络拓扑经网表核实：C8 是**芯片侧并联**到地，L1 与 R5 串在天线路径上，C13 / C14 是**天线侧并联调试位**（当前 DNP，不贴装即为开路）。

**② I²C 上升时间（SI）**　I²C 规范对上升时间的定义是 **30%~70%**，即 `t_r = 0.8473·R·C`，不是 10%~90% 的 `2.2RC`。

```
t_r = 0.8473 × 10 kΩ × 30 pF ≈ 254 ns
100 kHz 标准模式上限 1000 ns   →   满足，且约有 4 倍电容裕量
```

**③ 晶振负载电容（SI）**　板上两颗负载电容串联后与板级杂散并联：`C_L ≈ Ca·Cb/(Ca+Cb) + C_stray`。Y1（32 MHz，标称 8 pF）与参考设计一致；**Y2（32.768 kHz，标称 7 pF）估算负载约 9 pF，偏大**，按音叉晶振模型估算频率偏低约 **−45 ppm**（日计时约 3.9 s）。下一版可把 C9 / C10 由 12 pF 改为 8 pF。

**④ 本板供电的限制在电池，不在 PCB（PI）**　PCB 导电路径的直流压降 **< 0.5 mV**；而 CR2032 内阻（10~60 Ω）在 6 mA 下造成 **60~360 mV** 的压降，比前者高两个数量级以上。**本板 PI 分析的重点是电池内阻引起的负载压降与局部去耦。**

**⑤ 供电下限由 LCD 驱动决定（PI）**　工作范围 2.4 ~ 3.3 V，**下限由 U3（HT16C21A）的 2.4 V 决定**（nRF52810 可低至 1.7 V）。因此电量耗尽的先兆是 **LCD 先显示异常**，而不是 MCU 先掉电。按「寿命阶段 × 温度」的估算工况，常温工况均满足下限，末期低温工况下电池压降增大、LCD 驱动首先跌破；对应的**低电量告警阈值定为 2.8 V**。

**⑥ BT1 是唯一没有器件防护的入口（ESD）**　保护器件必须就近入口放置。BT1 与 J1 相距 25.8 mm，走线电感约 7.7 nH，在 30 A / 1 ns 的放电下感应压差约 **230 V**，放在 BT1 的器件来不及钳位。而 J1 的阵列中已含 VDD 通道（BT1.1 与 J1.1 同网络），在 BT1 重复放置只是"就近"之差，代价是 VDD 网络漏电翻倍。

因此 BT1 的处置写成：**优先用结构措施解决**——电池仓内缩或需工具开启，使手指无法触及金属夹片，从源头消除人体接触。若外壳设计做不到，再加一颗单向 TVS 对地。

## 3. 本周遇到的问题及处理

### 3.1 布局布线中的实际问题

**① 保护器件没有落脚点，J1 必须让位**

ESD 布局要求保护器件与连接器**同层且紧邻**。原 J1 在 (160.20, 61.80) 旋转 180°，其周边同层找不到既能放下 SOT-23-6、又满足保护前路径要求的空位。

处理：把 J1 北移并转 −90° 到 (160.90, 55.40)，在其南侧腾出 U4 的位置。代价是 SWDIO / SWDCLK / RESET / VDD 四条线全部重画，并连带把 SW1、R4、U2、C12、C1、C7 六处器件重新归位。

**② U2 的热隔离 keepout 卡住了它的就近接地**

U2（SHT40）的封装里嵌了一个 1.5 × 1.5 mm 的四层 keepout，规则是 `tracks ✗ / vias ✗ / copperpour ✗ / pads ✓`。这是第 4 周按 SHT4x 手册 §5.3 做的热隔离设计——但它同时意味着**去耦电容与接地过孔都不能进入这个框**。

处理：U2 的 pad 4（GND）不能就近打过孔，必须把孔落在 1.5 × 1.5 mm 框外再走短线引出去（现最近的 GND 过孔在 4.0 mm 外）；C12 也只能贴在框外沿摆放。

**③ 布线收尾时出现重合过孔与悬空过孔**

收尾阶段的 DRC 报出 4 条告警：三对 GND 过孔**位置完全重合**，一个 GND 过孔**只有一层有连接**。

重合过孔在屏幕上只显示为一个，单击也只选中一个，**靠单击删不干净**——必须用**框选**并看状态栏的选中数量确认。四处已全部清除，最终 DRC 不再出现。

### 3.2 参数与标准的确定

**① 保护前路径到底允许多长**

ESD 布局的通行说法是"保护器件到入口不超过 5 mm"，但本板 VDD 那一路从 J1 最北端绕到 U4 南排，**最短也做不到 5 mm**。为此把判据分了主次：

| 网络 | 判据 | 实测 |
|---|---|---|
| SWDIO / SWDCLK / RESET | **≤ 5 mm**（信号优先级高） | 3.66 / 3.83 / 7.25 mm |
| VDD | ≤ 10 mm 作为工作上限 | 15.98 mm，已在 U4 旁打过孔 |

放宽 VDD 的依据是**注入位置的能量集中度不同**：三条信号线是裸露焊盘直连 U1 引脚，能量集中在单个 ESD 结构上；而 VDD 网络有 2.2 µF 体电容和完整电源平面分摊。**单引脚受注比电源轨受注更危险**——这条判据也是 §2.2 决定 U4 不旋转 180° 的理由。

**② ESD 器件的漏电流按典型值还是最大值**

TT0554TLX 手册给的是**典型 0.1 µA / 最大 1.0 µA**（V_RWM = 5 V，25 °C）。本机静态电流只有约 20 µA：

```
按典型值：0.1 µA / 20 µA = 0.5%   → 看着可以忽略
按最大值：1.0 µA / 20 µA = 5%     → 必须计入续航预算
```

相差十倍。**本板一律按最大值核算**——典型值是统计中值，不能用来做功耗预算。这也是本板选型时把漏电流放在钳位电压之前的原因：通用 ESD 选型资料不会强调这一条，但本机的静态电流量级决定了它才是第一约束。

## 6. 本周总结

本周把板子从"布线完成"推到了"可以发板"：**ESD 防护器件落地，全部布线完成，DRC 维持 0 error / 0 未连接。**

ESD 这一块本板要解决的不是"加一颗 TVS"这么简单，而是三件事同时成立：**器件放得住、路径足够短、漏电付得起**。放得住——J1 北移让位，U4 与连接器同层紧邻；路径足够短——三条信号线的保护前长度做到 3.66 / 3.83 / 7.25 mm，且接入电源平面的过孔必须打在保护器件**之后**，打在中段等于让 ESD 电流绕过钳位点；漏电付得起——本机静态电流只有 20 µA，器件漏电要按手册**最大值**（1.0 µA）而不是典型值（0.1 µA）核算，两者差十倍。

贯穿本周的一个判断是：**保护优先级按能量集中度排，不是按"哪个入口更显眼"排。** SWDIO / SWDCLK / nRESET 是裸露焊盘直连 U1 引脚，能量集中在单个引脚；VDD 网络有 2.2 µF 体电容与完整平面分摊。这条判据直接决定了宁可让 VDD 那一路长到 15.98 mm，也不把 U4 转 180° 去换它——**用两条信号线的保护裕量换一条电源轨的长度，不划算**。

流程上记一条：**重合对象必须框选删除**。三对位置完全重合的 GND 过孔，屏幕上只显示一个，单击也只能选中一个，删了 DRC 依旧报错。

三份分析报告（SI / PI / ESD）本周交付，另外两份（热设计 / DFT）初稿已完成、正在修订。分析下来最有价值的一条结论是**把"限制在哪里"说清楚**：本板 PCB 侧的直流压降不到 0.5 mV，供电的真正瓶颈是 CR2032 的内阻（60~360 mV，高出两个数量级）；热设计的真正内容不是散热（全板峰值功耗 18 mW），而是把 SHT40 从板内热源旁边挪开。**把问题定位到真正的约束上，比在不是约束的地方做优化更有意义。**
