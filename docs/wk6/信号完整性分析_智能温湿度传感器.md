# 信号完整性分析

**项目**：智能温湿度传感器（方案 B） · 四层板 · nRF52810 + SHT40 + HT16C21A + 20×4 段码 LCD + CR2032
**日期**：2026-10-04（第 6 周）　**依据文件**：`正式工程_方案B.kicad_pcb`、各器件数据手册

本报告基于 PCB 几何数据、器件手册及参考设计，采用工程估算分析主要信号网络，为当前设计取值和后续调试提供依据。

## 3. I²C 总线

**依据**　R1/R2 = 10 kΩ 上拉。总线电容由三部分构成：nRF52810、SHT40、HT16C21A 的引脚电容，加 55.98 mm 总线的走线电容，合计估算约 **30 pF**。

```
t_r = 0.8473 × R × C = 0.8473 × 10 kΩ × 30 pF ≈ 254 ns

100 kHz 标准模式的上升时间上限为 1000 ns   →   满足该项要求
同一上拉阻值下，1000 ns 对应的总线电容上限 ≈ 118 pF   →   对 30 pF 的估算值有约 4 倍裕量
```

**结论**　按总线电容约 30 pF 估算，10 kΩ 上拉对应的上升时间约为 254 ns，满足 100 kHz 标准模式要求，并留有较充足的电容裕量，**当前上拉阻值可保留**。

**扩展**　若后续需要 400 kHz（上升时间上限 300 ns），需降低上拉阻值以保证总线电容增大时的裕量，并确认器件在全供电范围内的时序条件。

## 4. 射频链路

| 项 | 从 PCB 文件提取 / 计算 |
|---|---|
| 链路构成 | `Net-(U1-ANT)` 6.37 → `Net-(C13-Pad2)` 4.10 → `/ANT_FEED` 2.68 mm，合计 **13.15 mm**，全程 **F.Cu、0 个过孔** |
| 线宽 / 阻抗 | 除引脚引出段外全程 0.36 mm；计算 **49.8 Ω** |
| 参考平面 | In1 完整地平面（GND），介质 0.2104 mm |
| 天线净空区 | 全 4 层禁走线/过孔/焊盘/铺铜，馈电点处留缺口供馈线进入；无走线或过孔侵入 |

**匹配网络**（拓扑经网表核实）：

```
U1.ANT ─┬─ C8 0.8pF ─ GND                    贴装：芯片侧匹配
        └─ L1 3.9nH ─┬─ R5 0Ω ─┬─ AE1 天线     贴装：L1、R5 串联
                     │         │
                  C13 DNP    C14 DNP           预留：天线侧并联调试位
```

**芯片侧匹配**　L1 = 3.9 nH（串联）、C8 = 0.8 pF（并联到地），取值取自 Nordic nRF52810 参考设计；R5 为 0 Ω 串联元件。本板 AE1 采用 `Texas_SWRA117D_2.4GHz_Left`，与参考天线几何一致、净空区按参考尺寸封闭，参考取值适用。

**天线侧匹配**　C13、C14 为**并联**预留位，当前 DNP。并联支路不贴装即为开路，**不影响主路径连通**。调试时若实测驻波比偏高，优先在这两个位置调整，而非改动走线。

`Net-(U1-ANT)` 中有一段 0.70 mm 的 0.2 mm 宽走线，为 QFN-48 在 0.4 mm 引脚间距下的必要引出（0.36 mm 线宽无法直接连接该间距的焊盘）。该段**长度较短，按局部不连续处理**（附录 A.4）。

## 5. 晶振电路

| 晶振 | 两脚网络总长 | 换层 | 标称 C_L | 板上负载电容 | 估算 C_L |
|---|---|---|---|---|---|
| **Y1** 32 MHz（HCI XC21M4-32.000-F08NJDTL） | XC1 6.53 / XC2 6.31 mm | 0 | 8 pF | C15/C16 = 12 pF | 6 pF + C_stray |
| **Y2** 32.768 kHz（HCI FC31M2-32.768-N07LLDTL） | XL1 8.35 / XL2 8.23 mm | 0 | 7 pF | C9/C10 = 12 pF | 6 pF + C_stray |

两脚走线全程 F.Cu、下方为 In1 完整地平面、无长平行段，四颗负载电容的接地端均在 GND 网络上。

**负载电容**　板上两颗负载电容 Ca、Cb 串联后与板级杂散并联：

```
C_L ≈ Ca·Cb / (Ca + Cb) + C_stray = 12×12/(12+12) + C_stray = 6 pF + C_stray
```

**Y1（32 MHz）**　板上配置与 Nordic 参考设计一致。取 C_stray ≈ 3 pF 时 C_L 估算约 9 pF，相对标称 8 pF 偏大约 1 pF，**频率有向低侧偏移的趋势**，量级较小。

**Y2（32.768 kHz）**　相对标称 7 pF，**估算负载偏大，频率有向低侧偏移的趋势**。按音叉晶振通用模型估算偏差约 −45 ppm（附录 A.5），主要用于评估低频时钟精度。

**候选调整值**　若取 C_stray ≈ 3 pF，把 C9/C10 由 12 pF 改为 **8 pF** 可使 C_L 回到约 7 pF 的标称值。该取值建立在杂散约 3 pF 的假设上，**调试时结合实际计时与通信表现确认电容取值**。

## 6. 回流路径与串扰

**参考平面与换层回流**　两个信号层各紧贴一个完整平面（F.Cu→In1.GND，B.Cu→In2.PWR），介质均为 0.2104 mm，回流集中在走线正下方，满足该项要求。走线换层时回流需由 In1 转移到 In2：本板只有 In1（GND）与 In2（VDD）两层铺铜，GND 缝合过孔不能建立这个通路，**跨接两层的去耦电容**才是平面间通路（此外平面间本身存在分布电容，约 72 pF 量级，见《电源完整性分析》）。全部 17 个信号换层过孔对应的网络都是慢速信号，分析重点为参考平面的连续性。

**串扰**　结合板内互连距离、平行段长度及工作方式，低速接口的串扰风险初步判断较低。分析重点为参考平面连续性、换层后的回流路径及敏感网络之间的耦合。从 PCB 文件提取的几何数据显示：边距 < 0.3 mm 的平行段共 14 对，全部集中在 LCD 的 SEG/COM 网络与 I²C 上；最紧的一对为 I2C_SCL ↔ I2C_SDA，平行 13.20 mm、边距 0.200 mm（设计规则最小间距 0.20 mm，DRC 判定合规）。LCD 与 I²C 均属慢边沿网络，耦合能量有限。

用于评估耦合影响的噪声裕量（条件：VDD = 3.0 V；I²C 门限 V_IL,max = 0.3×VDD = 0.9 V、V_IH,min = 0.7×VDD = 2.1 V；器件 V_OL ≤ 0.4 V、V_OH ≈ VDD）：低电平裕量 0.5 V，高电平裕量 0.9 V。该数值用于说明接收端的抗扰能力，不单独作为串扰已通过的判据。

## 附录 A　计算依据

### A.1 叠层与传播参数

叠层 S-G-P-S：`F.Cu(1 oz) / In1.GND(0.5 oz) / In2.PWR(0.5 oz) / B.Cu(1 oz)`，外层到内层介质 H = 0.2104 mm（7628 PP，RC 49%，Er ≈ 4.4），芯板 1.065 mm，总厚 1.606 mm。

```
微带线等效介电常数：Er_eff = (Er+1)/2 + (Er-1)/2 × 1/√(1 + 12H/W)
```

| 线宽 W | W/H | Er_eff | 传播速度 v | 传播延迟 | λ @ 2.4 GHz |
|---|---|---|---|---|---|
| **0.36 mm**（射频） | 1.71 | **3.30** | 1.652 × 10⁸ m/s | **6.05 ps/mm** | **68.8 mm** |
| 0.20 mm（其余） | 0.95 | 3.16 | 1.688 × 10⁸ m/s | 5.92 ps/mm | 70.3 mm |

> Er_eff 随线宽与场分布变化，上表为近似值。§2 的判据结论对该差异不敏感，但射频链路的电长度应按 0.36 mm 线的参数（λ = 68.8 mm）计算。

### A.2 传输线判据

```
L > v · t_r / 6   →   按传输线处理
```

系数取 1/6 为工程惯用值，随允许误差、端接方式与源/负载阻抗在 1/2~1/10 之间变化。

### A.3 I²C 上升时间

```
I²C 规范（UM10204）定义的上升时间为 30%~70%：
  t_r = R·C·ln(0.7/0.3) = 0.8473·R·C
      = 0.8473 × 10⁴ × 30×10⁻¹² ≈ 254 ns

100 kHz 标准模式的上限 1000 ns 对应的总线电容：
  C = 1000×10⁻⁹ / (0.8473 × 10⁴) ≈ 118 pF
```

### A.4 射频引脚引出段

`Net-(U1-ANT)` 中 0.70 mm 的 0.2 mm 宽段，按微带线（W/H = 0.95 < 1）经验式：

```
Z₀ = (60/√Er_eff) · ln(8H/W + W/4H) ≈ 73 Ω
电长度 = 0.70 / 68.8 × 360° ≈ 3.7°
```

### A.5 晶振负载电容与可调率

```
C_L ≈ Ca·Cb/(Ca+Cb) + C_stray

Y1：Ca = Cb = 12 pF → 6 pF + C_stray；标称 8 pF
Y2：Ca = Cb = 12 pF → 6 pF + C_stray；标称 7 pF
```

频率随负载电容的变化（C_m = 动态电容、C_0 = 静态电容，均为晶体等效电路参数，取自器件手册，与板上电容位号无关）：

```
精确式：Δf/f = (C_m/2) × [ 1/(C_0 + C_L2) − 1/(C_0 + C_L1) ]

Y2（32.768 kHz），取音叉通用参数 C_m = 3.7 fF、C_0 = 1.1 pF，
C_L 由标称 7 pF 变为估算 9 pF：
  Δf/f = (3.7×10⁻¹⁵/2) × [ 1/10.1×10⁻¹² − 1/8.1×10⁻¹² ]
       ≈ −4.5×10⁻⁵ = −45 ppm   （模型估算值，日计时约 3.9 秒）

Y1（32 MHz）：AT-cut 晶振的可调率通常在数十 ppm/pF 量级
  （典型 C_m = 5~10 fF、C_0 = 1.5~2 pF 时约 25~55 ppm/pF），本报告不作定量估算。
```

> 上式对 C_L 是非线性的。若改用线性近似 `C_m/[2(C_0+C_L)²] · ΔC_L`，在标称点展开得 −56 ppm、在实际点展开得 −36 ppm，同一组输入下相差约 20 ppm，故采用精确式。
