# 热设计分析

**项目**：智能温湿度传感器（方案 B） · 四层板 · nRF52810 + SHT40 + HT16C21A + 20×4 段码 LCD + CR2032
**日期**：2026-10-04（第 6 周）　**依据文件**：`正式工程_方案B.kicad_pcb`、各器件数据手册

本报告依据器件手册与 PCB 几何数据，分析本板的功耗、结温与热耦合，为当前设计取值和后续调试提供依据。

---

## 1. 功耗

### 1.1 主要器件的电流

| 器件 | 状态 | 电流 | 依据 |
|---|---|---|---|
| **U1** nRF52810（整芯片） | 射频发射 @0 dBm（DCDC） | **4.6 mA** | Nordic PS §6.14.15.2 |
| | CPU 运行 CoreMark @64 MHz（DCDC） | 2.2 mA | Nordic PS §5.2.1.1 |
| | System ON 睡眠 + RTC（LFRC） | 1.5 µA | Nordic PS §5.2.1.3 |
| **U2** SHT40 | 测量期间 / 空闲 | 0.5 mA / 0.1 µA | SHT4x 手册 |
| **U3** HT16C21A | LCD 显示开启 / 待机 | 18 µA / ≤ 1 µA | HT16C21A 手册 |
| **D1 + R3** | 状态灯点亮 | 0.45 mA | 见 §1.3 |
| **U4** TT0554TLX | 静态漏电 | 0.1 µA（典型） | TT0554TLX 手册 |

> 表中为**整芯片电流**，对应手册规定的各自工作状态，不能按"模块电流"直接相加；电压统一按标称 **3.0 V** 计算。

### 1.2 峰值功耗

条件：射频发射与片外负载同时工作（CPU 在发射期间处于 WFI）。

```
U1 射频发射（整芯片）   4.6  mA
D1 + R3  LED 点亮       0.45 mA
U2 SHT40 测量中         0.5  mA
───────────────────────────────
整板峰值电流            ≈ 5.6 mA
取设计值                 6 mA     ← 当前假设工况下的设计取值，与《电源完整性分析》§4 同口径

P_peak = 3.0 V × 6 mA = 18 mW
```

### 1.3 LED 支路电流

```
U1 GPIO → R3 (2.2 kΩ) → D1（绿色 0805 LED）→ GND
I = (V_GPIO − V_F) / R3 = (3.0 − 2.0) V / 2.2 kΩ ≈ 0.45 mA
```

### 1.4 代表性周期的平均功耗

设计假设（非实测）：BLE 广播间隔 **1 s**、单次广播发射（3 信道合计）**1.5 ms**；传感器采样间隔 **60 s**、单次测量 **8.3 ms**；每次广播后 CPU 处理 **3 ms**；LCD 常显。

以 **60 s** 为一个周期统计：

| 状态 | 整机电流 | 单周期时长 | 电荷 |
|---|---|---|---|
| System ON 睡眠（RTC） | 1.5 µA + LCD 18 µA = **19.5 µA** | 59.72 s | 1165 µA·s |
| CPU 处理 | 2.2 mA + LCD = **2.218 mA** | 0.180 s | 399 µA·s |
| 射频发射 | 4.6 mA + LCD = **4.618 mA** | 0.090 s | 416 µA·s |
| 传感器测量 | 0.5 mA + LCD = **0.518 mA** | 0.0083 s | 4.3 µA·s |
| **合计** | | **60 s** | **1984 µA·s** |

```
I_avg = 1984 µA·s / 60 s ≈ 33 µA
P_avg = 3.0 V × 33 µA ≈ 0.1 mW
```

**结论：峰值 18 mW、周期平均约 0.1 mW，本板不存在散热问题。** 实际值需在样机上按《DFT 可测试性设计说明》§2 分档测量确认。

## 2. 结温估算

### 2.1 公式与取值

```
ΔT_j = θ_JA × P          T_j = T_a + ΔT_j
```

- **T_a 取 40 °C**（室内设备的环境温度上限工况）；
- **P 取芯片输入电功率** `VDD × I`，为保守近似；
- **θ_JA 按所选范围上限估算**。

> nRF52810 规格书**未公布 θ_JA**，也**未给出结温上限**——**85 °C 是环境温度 TA 的上限**（PS Table 107 Recommended operating conditions），因此本报告不就结温余量作论断。

### 2.2 各器件温升

| 器件 | P | θ_JA | ΔT_j |
|---|---|---|---|
| **U1** nRF52810 | 13.8 mW（4.6 mA × 3.0 V） | 25 ~ 50 °C/W | **0.35 ~ 0.69 °C** |
| **U3** HT16C21A | 54 µW（18 µA × 3.0 V） | 80 ~ 100 °C/W | **≈ 0.005 °C** |
| **U2** SHT40 | 1.5 mW | 297 K/W | 见 §2.3 |

θ_JA 取值依据：U1 按"6×6 mm 带散热焊盘 QFN、四层板、下方有地平面与过孔阵列"的通用范围（Nordic 未公布）；U3 按 SSOP-28 通用值；U2 取手册 Table 10。

**U1 按峰值功耗且假设其持续存在估算**，得到的是结温升上界；正常运行主要取决于平均功耗（§1.4，0.1 mW 量级），远低于此。即使把 θ_JA 放大到 150 °C/W，ΔT 也只有 2 °C。

**按上述热阻取值估算，最热器件结温升约为 0.7 °C，无需额外散热措施。**

### 2.3 SHT40 自热

**模型假设**　采用一阶集总热 RC 模型估算单次测量的自热温升：裸片温度近似均匀；短时间测量期间外壳温度近似不变；测量开始时裸片与外壳温度相同。热时间常数以**裸片热容 C_die** 与**结到壳热阻 R_θJC** 估算。

**参数及取值依据**　结到壳热阻取报告所引手册 Table 10 中「散热焊盘不焊接」一列的 **R_θJC = 191 K/W**（与本板无中央焊盘的封装一致）。裸片尺寸按 **1.0 mm × 1.0 mm × 0.2 mm** 假设；硅的密度取 2330 kg/m³，比热容取 700 J/(kg·K)。

<div class="keybox" markdown="1">
<p class="kb-title">热时间常数</p>

```
V_die = 1.0 × 1.0 × 0.2 mm³ = 2.0 × 10⁻¹⁰ m³

C_die = ρ × c × V_die
      = 2330 × 700 × 2.0 × 10⁻¹⁰
      ≈ 3.3 × 10⁻⁴ J/K

τ = R_θJC × C_die
  = 191 × 3.3 × 10⁻⁴
  ≈ 0.063 s
  ≈ 60 ms
```

该时间常数为上述假设下的工程估算值。

</div>

**单次测量自热估算**　测量电压取 3 V、测量电流取 0.5 mA、持续时间取 8.3 ms（高重复度），将测量功耗近似为恒定发热功率。

```
P = U × I = 3 V × 0.5 mA = 1.5 mW

ΔT(t) = P × R_θJC × [1 − exp(−t / τ)]

ΔT(8.3 ms) = 0.0015 × 191 × [1 − exp(−8.3 / 60)]
           ≈ 0.037 °C
           ≈ 0.04 °C
```

**周期运行**　占空比 D = 8.3 ms / 60 s ≈ 1.4 × 10⁻⁴：

```
P_avg = 3.0 V × [ 0.5 mA × D + 0.1 µA × (1 − D) ] ≈ 0.5 µW
ΔT_avg = R_θJA × P_avg = 297 K/W × 0.5 µW ≈ 0.00015 °C
```

**结论：按该模型，单次测量结束时裸片相对外壳的自热温升约为 0.04 °C；周期平均自热可忽略。**

## 3. 热耦合估算

SHT40 测量的是**自身芯片的温度**，受热会直接导致温度读数偏高，并影响相对湿度读数。本节估算板内自发热对它的影响。

### 3.1 模型

把传感器看作热阻网络中的一个节点：一侧经 `R_bs` 连到它所在位置的 PCB，另一侧经 `R_sa` 连到环境。忽略传感器自热（自热见 §2.3），稳态下两段热阻上的热流相等，整理得：

```
ΔTs = ΔTb × R_sa / (R_bs + R_sa)

  Tb：传感器附近 PCB 的温度      Ts：SHT40 的温度      Ta：环境温度
  ΔTs = Ts − Ta                  ΔTb = Tb − Ta
```

### 3.2 参数

| 参数 | 取值 | 依据 |
|---|---|---|
| **R_bs** | **≈ 400 K/W** | 局部传热路径的**示例估算值**：传感器下方 keepout 区（1.5×1.5 mm，四层无铜）的 FR4 段，`R = L / (k·A) = 0.2104 mm / (0.3 W/(m·K) × 1.65 mm²)`。焊盘及所连走线存在并联导热路径，实际等效热阻可能更低 |
| **R_sa** | **≈ 37000 K/W** | 传感器顶面到环境：`1 / (h_s × A_s) = 1 / (12 W/(m²·K) × 2.25 mm²)`。h_s 含自然对流与辐射；A_s 为 1.5×1.5 mm 顶面 |
| **R_ba** | **≈ 26 K/W** | 板到环境：`1 / (h_b × 2A_board) = 1 / (10 W/(m²·K) × 2 × 1928 mm²)`。板 48.2 × 40 mm，双面自然散热 |
| P_avg | 0.1 mW | §1.4 |

### 3.3 计算

```
ΔTb ≈ P_avg × R_ba = 0.0001 W × 26 K/W ≈ 0.0026 °C

ΔTs ≈ 0.0026 × 37000 / (400 + 37000) ≈ 0.003 °C
```

**说明**：以上按板温近似均匀、双面自然散热进行量级估算，表明正常低占空比运行下，板内自发热对测温的影响预计较小。

> 由 `R_sa ≫ R_bs` 可知传感器温度接近其所在位置的板温，因此决定耦合量级的是 **ΔTb**（即全板平均功耗），而非 R_bs 的精确取值。

### 3.4 布局措施

1. **远离主控与 LED**——U2 距 U1 25.5 mm、距 D1 32.6 mm、距 L2 20.3 mm；
2. **传感器下方设无铜区**——封装内嵌 1.5 × 1.5 mm 四层 keepout（SHT4x 手册 §5.3 要求），切断铜层把远处热量导到传感器正下方的路径；
3. **周围避免持续发热器件**——U2 附近 8 mm 内仅有去耦电容 C12（2.4 mm）、上拉电阻 R4（4.1 mm）等低功耗无源器件，无持续显著热源。
