# DFT 可测试性设计说明

**项目**：智能温湿度传感器（方案 B） · 四层板 · nRF52810 + SHT40 + HT16C21A + 20×4 段码 LCD + CR2032
**日期**：2026-10-04（第 6 周）　**依据文件**：`正式工程_方案B.kicad_pcb`、`正式工程_方案B.kicad_sch`

本报告以当前样机的**测试资源**与**测试实施方案**为主，回答三个问题：目前有哪些可用的测试接口或接入位置；各功能如何测试；不同工作状态下的功耗如何测量与判断。

---

## 1. 测试资源清单

### 1.1 汇总

| 资源 | 接入位置 | 测试用途 | 当前限制 |
|---|---|---|---|
| **SWD** | J1（2×5，1.27 mm，B.Cu 板边） | 固件烧录、在线调试、读寄存器与内存；配合 RTT 输出运行日志 | — |
| **UART** | **未引出** | 串口日志输出、测试指令交互 | 本版无走线；日志调试可用 SWD + RTT 替代 |
| **I²C** | R1/R2 总线侧焊盘、U2/U3 引脚 | 器件通信与功能验证（SHT40、HT16C21A） | 无专用测试点，可利用现有总线焊盘接入 |
| **整板电流** | J1 的 VDD/GND，或 BT1 电池座焊盘 | 拔出电池后由外部测量电源供电，测整板电流 | 需外部源表/电流表；不能在装电池状态下测量 |
| **电池电压** | 芯片内部（SAADC 的 VDD 通道） | 低电量判断 | 无需外部元件 |
| **LED / 按键 / LCD** | 板上器件 | 目视与手动确认 | 需人工参与 |

> **关于 J1 的 pin 1（VDD）**：该脚是调试器的**电压参考（VTref）**，不代表所有调试器都能从它给目标板供电。测试供电应由**外部电源**提供，或使用已确认支持目标供电的调试设备。

### 1.2 SWD

固件烧录、在线调试、读寄存器与内存。**配合 RTT（Real Time Transfer）可输出运行日志**，用于观察固件的状态切换（RTT 需调试器支持，如 J-Link）。

> SWD 连通只能说明**基本供电及调试通信正常**，不能证明所有焊点和功能均正常——后者由 §3.2 的功能检查覆盖。

### 1.3 UART

**当前版本未引出。** 其用途是串口日志输出与测试指令交互。

现阶段**可通过 SWD 配合 RTT 完成日志调试**；后续如有需要，可在 J1 的空闲脚上预留 TX 测试点，需要接收指令时再增加 RX。本版不因此修改原理图或 PCB。

### 1.4 I²C

I²C 上有一颗主控、两颗从器件，通过 MCU 测试固件检查其通信与功能：

| 器件 | 地址 | 检查内容 |
|---|---|---|
| U2 SHT40 | 0x44 | 地址应答、温湿度读取、**CRC 校验** |
| U3 HT16C21A | — | 显示 RAM 写入 / 回读，配合 LCD 全亮、全灭及交替段图案检查 |

需要观察波形时，可从 **R1/R2 的总线侧焊盘**接入探头。

### 1.5 整板电流测量

**拔出电池后，通过 J1 的 VDD/GND 或 BT1 电池座焊盘接入外部测量电源，即可测量整板电流。**

现有供电接入位置已经可以支持测量；串联 0 Ω 电阻或跳线属于**后续的便利性改进**（§3.3），不作为当前测试的前提。

### 1.6 电池电压监测

低电量告警阈值定为 **2.8 V**（推导见《电源完整性分析》§4.3）。nRF52810 的 SAADC 可直接把 VDD 选作输入通道（PS Table 69），**不需要外部分压电阻，也不占用 GPIO**。

## 2. 功耗分档测量方案

### 2.1 为什么分档

整机电流随固件状态在 µA 到 mA 之间跨三个数量级，只测一个总数无法定位问题。分档测量把总电流拆成可归因的几项：各档**固定背景状态、只切换一个功能块**，测得值与该档的参考值比对。

### 2.2 档位定义

| 档 | 固件状态 | 参考电流 | 说明 |
|---|---|---|---|
| **1 基础睡眠** | System ON 睡眠 + RTC，LCD 关、传感器空闲、射频与 LED 关 | ≈ **3.6 µA** | 检查基础休眠电流与漏电。**该值混合了手册典型值与最大值，只作参考预算，不作精确验收阈值** |
| **2 正常显示待机** | 档 1 + LCD 常显 | ≈ **20 µA** | 与《热设计分析》§1.4 的正常待机状态对应 |
| **3 CPU 活动** | CPU 运行、射频关闭，其余外设状态固定 | ≈ **2.2 mA** | 手册对应运行条件下的参考值；**不同固件的空转电流不一定相同** |
| **4 传感器测量** | 固定 CPU、LCD 等背景状态，触发一次测量 | 增量 **+0.5 mA**，持续 8.3 ms | 观察**增量与持续时间**，避免把背景状态变化误认为传感器功耗 |
| **5 射频发射** | 与热设计同假设：CPU 在发射期间睡眠，BLE TX @0 dBm、DCDC 开启、LCD 显示 | ≈ **4.62 mA** | `4.6 mA + 0.018 mA` |
| **6 LED** | 固定其他状态，仅切换 LED | 增量 ≈ **0.45 mA** | 比较切换前后的差值 |
| **7 完整工作周期** | 与热设计相同的广播、采样、CPU 处理与显示策略 | ≈ **33 µA** | **正常使用续航主要依据这一档**，而不是关闭 LCD 后的基础睡眠档 |

> **System OFF 若需测试，可单列为「深度休眠」档。** nRF52810 本身的参考电流为 **0.3 ~ 0.5 µA**，**整板电流还需计入** LCD 驱动待机、传感器空闲及保护器件漏电。该档不与 System ON + RTC 档混用。

第 7 档的假设与《热设计分析》§1.4 一致：BLE 广播间隔 **1 s**、单次广播发射 **1.5 ms**；传感器采样间隔 **60 s**、单次测量 **8.3 ms**；每次广播后 CPU 处理 **3 ms**；LCD 常显。

### 2.3 接线与步骤

```
1  通过 SWD 烧录对应的测试固件
2  拔出电池，源表正端接 VDD、负端接 GND
   （若用独立电源 + 电流表，将电流表串入供电支路）
3  退出调试，关闭 RTT / UART 日志及不需要的外设；
   必要时断开调试信号后重新上电
   ！确保整板仅由测量电源供电，避免调试器或其他接口形成额外供电路径
4  等待进入规定状态，记录电流
5  各档保持相同的供电电压与明确的外设状态
```

整机电流按仪器读数记录：

```
I_board = I_measured
```

> **不扣除 U4 的漏电流。** U4 是板上负载，其漏电本来就是整机功耗的一部分，不能减去手册的典型值或最大值。

### 2.4 仪器与记录

- 稳定的 µA 级电流可用适合量程的万用表、源表或功耗分析仪测量；**毫秒级采样与射频脉冲需要具备足够采样速度的设备**；
- 测完整周期平均值时，覆盖**至少一个完整采样周期**，并包含多个广播事件；
- 建议记录：**测试档位、供电电压、固件状态、参考电流、实测电流、异常说明**。

## 3. 测试流程与可选改进

### 3.1 测试顺序

```
1  目视检查        ── 缺件、错件、极性、桥连
2  限流上电        ── 3.0 V / 限流 20 mA，看电流是否正常
3  SWD 连接及烧录
4  功能检查        ── 见 §3.2
5  退出调试
6  功耗分档测量    ── 见 §2.2 第 1~6 档
7  完整周期测量    ── 见 §2.2 第 7 档
```

**功耗测量必须在烧录测试固件之后进行**——进入规定状态依赖固件。

> **上电注意**：首次上电采用**限流电源**，检查供电极性并观察电流；确认无明显短路后，再进行功能与功耗测试。CR2032 的短路电流可达数十 mA，若板上存在焊接短路，直接上电池既查不出问题，又会让电池发热。

### 3.2 功能检查清单

| # | 测试项 | 判据 | 需人工 |
|---|---|---|---|
| 1 | I2C 扫描 | 0x44 地址有应答（SHT40） | 否 |
| 2 | SHT40 读温湿度 | 在**规定的室内测试环境下**，读数落在 15~35 °C / 20~80 %RH，CRC 正确；**环境稳定、按固定间隔读取时**连续两次变化 < 0.5 °C（该项只反映读数稳定性，不代表测量准确度） | 否 |
| 3 | HT16C21A **显示 RAM** 写入 / 回读 | 写入值与回读值一致 | 否 |
| 4 | LCD 全亮 / 全灭 / 交替段 | 目视无缺段、无重影 | **是** |
| 5 | LED | 置高点亮、置低熄灭 | **是** |
| 6 | 按键 | 按下时 P0.11 读到低电平 | **是** |
| 7 | 32.768 kHz 时钟 | 外部低频晶振启动成功，RTC 能按设定周期产生事件 | 否 |
| 8 | 电池电压读数 | SAADC 读数与源表电压一致（±2%） | 否 |
| 9 | BLE 广播 | 手机能搜到设备名并读取广播数据 | **是** |

### 3.3 可选改进（非本版必须）

| # | 建议 | 代价 | 触发条件 |
|---|---|---|---|
| 1 | J1 的空闲脚（pin 6 / pin 8）预留 **UART TX** 测试点 | 1 条走线 | 需要串口日志且不便使用 RTT 时 |
| 2 | I²C 增加测试点 | 2 个过孔 | 需要频繁观测总线波形时 |
| 3 | BT1 与 VDD 平面之间串 **0 Ω 电阻 / 跳线** | 一个 0805 焊盘 + 一条走线 | 希望不拔电池即可测电流时 |

---

**结论**：当前版本具备 **SWD 调试、I²C 功能验证及整板电流测量**的基本条件，可通过测试固件实施功耗分档和完整周期测量。UART 暂未引出，可利用 **SWD 配合 RTT** 输出日志；后续根据实际调试需要，再考虑 UART、I²C 测试点及可断开的电流测量连接。

**参考**：Nordic nRF52810 产品规格书（§5.2 电流、§6.14.15 射频电流、Table 69 SAADC）；Sensirion SHT4x 数据手册；HT16C21A 数据手册；TT0554TLX 规格书；《电源完整性分析》§4.3；《热设计分析》§1.4；`正式工程_方案B.kicad_pcb` / `.kicad_sch` 提取的器件坐标与 J1 引脚分配。
