# 开源智能温湿度传感器 Pro PCB 设计——第 1 周实验报告

> 姓名：谢天成  
> 项目周期：第 1 周（2026.08.24—2026.08.30）  
> 本周阶段：需求分析、资料调研与 KiCad 基础练习

---

## 1. 本周目标

本周主要目标是了解智能温湿度传感器项目的整体要求，完成竞品与核心器件调研，并通过一个两层板练习熟悉 KiCad 的基本设计流程，为后续正式原理图和 PCB 设计做好准备。

## 2. 本周完成情况

### 2.1 项目需求与竞品分析

- 梳理了项目的主要功能、成本、功耗、尺寸及生产要求。
- 对米家蓝牙温湿度计 2、青萍温湿度计 Lite 和美德时蓝牙温湿度记录仪进行了初步对比。
- 将产品方案划分为极简广播版、标准带屏版和高精度 Pro 版，并确定优先完成模块最少的极简广播版。
- 发现 nRF52810 与 SHT40 两颗核心器件的量产价格已经超过 15 元，因此后续需要进一步确认成本上限的统计口径。

### 2.2 核心器件与系统方案

- 主控初步选用 **nRF52810 QFN48**，温湿度传感器选用 **SHT40-AD1B**。
- 电源采用 **CR2032 直接供电**，不额外使用 LDO，以降低静态功耗和器件数量。
- 确定了 SHT40 的 I²C 接口、按键、状态 LED、电池电压检测及 SWD 调试接口的基本连接方案。
- 学习了 nRF52810 的电源去耦、32 MHz 晶振、低频晶振、射频匹配网络和 PCB 天线的基本作用。

### 2.3 KiCad 实践进度

- 完成了两层板练习，初步熟悉了原理图绘制、封装分配、PCB 更新、元件布局、走线和铺铜的基本操作。
- 完成当前版本原理图的主要模块连接，包括 nRF52810、SHT40、CR2032、按键、LED、SWD 接口、晶振及射频网络。
- 对电阻、电容、晶振、QFN48、SHT40 和接口等器件的封装进行了检查和调整。
- 完成 ERC 检查中的主要错误整改，并理解了 `PWR_FLAG`、未连接引脚、DNP 元件和电源网络的处理方式。
- 已将原理图导入 PCB，完成板框及主要器件的初步布局，目前处于正式布线开始前的检查阶段。

## 3. 本周遇到的问题及处理

| 问题 | 处理情况 |
|---|---|
| 对 KiCad 操作不熟悉，开始时无法形成完整设计流程 | 先完成简单两层板练习，再逐步转入正式电路设计 |
| nRF52810 符号、物理引脚和封装之间容易混淆 | 对照数据手册与 QFN48 封装逐项核对，功能信号采用网络标签连接 |
| 不理解射频匹配网络及 DNP/N.C. 元件 | 参考 nRF52 射频电路保留匹配网络，并对可选器件使用 DNP 标注 |
| ERC 出现电源输入未驱动等错误 | 增加必要的 `PWR_FLAG`，检查电池、电源和 GND 网络连接 |
| PCB 布局时飞线较多，难以判断器件关系 | 按电源、主控、晶振、传感器、调试和射频模块分区，并优先保证去耦、晶振和射频器件靠近对应引脚 |

## 4. 当前进度评估

第 1 周计划中的项目理解、竞品调研、核心器件选型和 KiCad 入门练习已基本完成。产品需求分析报告仍需要补充部分价格、规格来源及最终验收指标。实践方面已经提前进入原理图设计和 PCB 布局阶段，但正式布线、铺铜及 DRC 尚未完成。

整体进度基本符合计划，并比原定安排提前开始了第 2～3 周的部分工作。当前主要风险是射频布局布线经验不足，以及正式设计要求为四层板，而现阶段仍主要通过两层板练习理解基础操作。

## 5. 下周计划

1. 完成 PCB 剩余布局检查，重点确认去耦电容、晶振、射频匹配网络和天线净空区。
2. 按照电源、晶振、射频、I²C 和普通 GPIO 的优先级完成布线。
3. 完成 GND 铺铜、电源网络处理和必要的过孔放置。
4. 运行 DRC，并记录和整改主要错误。
5. 继续完善产品需求分析报告，确认 BOM 成本统计口径及四层板叠层要求。

## 6. 本周总结

本周完成了从项目需求理解到 KiCad 实际设计的初步过渡。通过两层板练习和当前原理图设计，我对原理图、封装、PCB 布局及电气检查之间的关系有了更清晰的认识。下一阶段将重点完成布线和设计规则检查，同时进一步学习电源回流路径、射频走线和四层板布局原则。
