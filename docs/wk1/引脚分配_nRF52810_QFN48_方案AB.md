BLE_TempHumidity_2Layer_Practice# nRF52810 QFN48（QFAA）引脚分配 —— 方案 A / B

> 用途：第 2 周画原理图时的引脚分配依据。
> 对应器件：NRF52810-QFAA-R（QFN48，6×6mm，0.5mm pitch）
> 数据手册：`数据手册/Nordic_nRF52810_PS.pdf`

---

## 0. 重要说明（先读）

1. **物理引脚号（Pin 1/2/3…）以数据手册 QFN48 引脚表或 KiCad 符号为准**。本文只做「功能 → GPIO」映射，不标物理脚号，避免记错。
2. nRF52 的 I²C / SPI / UART / ADC 外设通过 PSEL 可映射到**任意 GPIO**，下面给的是**建议值**，可按布局就近调整。
3. **nRF52810 只有 32 个 GPIO（P0.00–P0.31）**，QFN48 多出来的脚是电源/地/射频/晶振/调试等**专用脚**。

---

## 1. 固定引脚（由封装决定，不能改）

| 引脚名 | 用途 | 连接 |
|--------|------|------|
| VDD | 电源（多脚） | 接 3V，就近去耦 |
| VSS | 地（多脚） | 接 GND 平面 |
| DEC | 内部 LDO 去耦 | 接 ~100nF 到地 |
| ANT | 射频输出 | → π 匹配网络 → 50Ω 馈线 → PCB 天线 |
| XL1 / XL2 | 32MHz 晶振 | 接 32MHz 晶振 + 负载电容 |
| SWDIO / SWDCLK | 调试口 | 引出测试点 / 焊盘 |
| nRESET | 复位 | 上拉，可选引出 |

> ⚠️ **待核对**：nRF52810 是否支持 32.768kHz 晶振（LFXO）。印象中 nRF52810 **可能只有 32MHz 晶振 + 内部 RC**、没有 32.768k 晶振脚——请对照数据手册确认。若确实没有，§6 BOM 里的「32.768kHz 晶振」要删（省 ~0.5 元，也少两个脚）。

---

## 2. 方案 A（极简广播版）信号分配

| 功能 | 信号 | 建议 GPIO | 说明 |
|------|------|----------|------|
| SHT40 | SDA | P0.06 | I²C 数据（非 ADC 脚） |
| SHT40 | SCL | P0.07 | I²C 时钟 |
| 状态 LED | LED | P0.08 | 串限流电阻，亮灭极性按实际电路定 |
| 按键 | KEY | P0.11 | 对地，内部上拉 |
| 电池检测 | BAT_ADC | P0.02（AIN0） | 电阻分压后进 ADC 测电量 |
| 调试 | SWDIO / SWDCLK | 专用脚 | 引出测试点 |
| 其余 GPIO | — | NC | 悬空，可留测试点 |

---

## 3. 方案 B（标准带屏版）在 A 基础上增加

| 功能 | 信号 | 建议 GPIO | 说明 |
|------|------|----------|------|
| 段码 LCD | 驱动 | 待定 | nRF52810 **无内置 LCD 控制器**，需外部驱动 IC（如 HT1621，3~4 线串行）或直接 GPIO；引脚取决于所选屏幕 |

> 建议：方案 B 的 LCD 优先选**带 I²C / 串行驱动 IC 的段码屏模块**，只占 2~4 个 GPIO，不挤占已有引脚，也省去大量段码走线。

---

## 4. 待核对清单（画原理图前必须确认）

1. **物理引脚号**：对照 `Nordic_nRF52810_PS.pdf` 的 QFN48 引脚表 / KiCad 符号。
2. **32.768kHz 晶振是否有**（见第 1 节）——影响 §6 BOM 和晶振脚数量。
3. **ADC 引脚映射**（AIN0–AIN7 ↔ P0.xx）以数据手册为准，P0.02 是否为 AIN0 需确认。
4. **方案 B 的 LCD 具体型号** → 驱动方式 → 引脚数。
5. LED 点亮极性（高/低电平）与按键上拉/下拉，按实际电路定。
